# 和鸣 M4 文件完善实现计划（持久化 · 投递 · 预览 · 配额）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 共享文件库落 Store 持久化（重启不丢）；右栏文件行 hover 投递到当前会话与预览（文本/Markdown/图片内嵌）；每用户存储总量配额（服务端校验 + 右栏用量展示）。

**Architecture:** 文件从 app.ts 内存 Map 迁入 Store 双实现（memory + sqlite 契约测试双跑，blob 以 base64 TEXT 落 sqlite）；投递经 ui store 的 `pendingAttachment` 单槽由 ChatPage 消费（右栏无 WS 句柄，避免全局 socket）；预览用既有鉴权 blob 链路（`fetchFileBlobUrl`）+ 无依赖 Markdown 轻渲染（纯 React 节点，不使用 innerHTML）。

**Tech Stack:** Express 5 + ws + node:sqlite；React 18 + Tailwind3 + Zustand；Vitest（server supertest / store 契约双跑 / web testing-library）。不新增依赖。

## Global Constraints

- 不新增任何 npm 依赖；Markdown 预览只允许正则分行 + React 文本节点（**禁用 dangerouslySetInnerHTML**）。
- 既有附件契约不变：`MessagePayload.file = {id,name,mime,size?…}`；`GET /api/files/:id/content` Bearer 鉴权口径不变；单文件上传客户端上限 6MB、服务端 json 8MB 不变。
- 共享库语义（本计划裁定并回填文档）：**云端共享 = 登录可见**——列表与 content 对任一登录用户开放；`DELETE` 保持属主校验。不做会话级 ACL（超 M4 范围，记入遗留）。
- 配额：每用户默认 **200MB**，env `HEMING_FILE_QUOTA_MB` 可覆盖；超限上传拒绝（HTTP 413，error code `quota_exceeded`），已超限文件不可通过重传绕过（校验含本次文件）。
- UI：无 emoji 图标（细线 SVG 1.5px）；分割线 `#e6e6e6`/`#ececec`；hover 操作用 `group-hover` 渐显；中文文案。
- Store 改动必须 memory/sqlite 双实现同改，`storeContract.test.ts` 双跑通过；sqlite 经 `createRequire("node:sqlite")`（db.ts 现有路径），表 `IF NOT EXISTS` 幂等。
- 所有新组件/接口配 vitest；`pnpm -r build && pnpm -r test` 全绿后提交。

```ts
    addFile(meta, contentBase64) {
      files.set(meta.id, { meta, contentBase64 });
      return meta;
    },
    getFile(id) {
      return files.get(id) ?? null;
    },
    listFiles() {
      return [...files.values()].map((f) => f.meta).sort((a, b) => (a.updatedAt < b.updatedAt ? 1 : -1));
    },
    deleteFile(id) {
      return files.delete(id);
    },
    userFileBytes(ownerUsername) {
      let sum = 0;
      for (const f of files.values()) if (f.meta.owner === ownerUsername) sum += f.meta.size;
      return sum;
    },
```

`sqliteStore.ts` 对应实现：

```ts
    addFile(meta, contentBase64) {
      db.prepare(
        "INSERT INTO shared_files (id, owner, name, mime, size, updated_at, content_base64) VALUES (?, ?, ?, ?, ?, ?, ?)",
      ).run(meta.id, meta.owner, meta.name, meta.mime, meta.size, meta.updatedAt, contentBase64);
      return meta;
    },
    getFile(id) {
      const row = db
        .prepare("SELECT id, owner, name, mime, size, updated_at, content_base64 FROM shared_files WHERE id = ?")
        .get(id) as
        | { id: string; owner: string; name: string; mime: string; size: number; updated_at: string; content_base64: string }
        | undefined;
      if (!row) return null;
      return {
        meta: { id: row.id, owner: row.owner, name: row.name, mime: row.mime, size: row.size, updatedAt: row.updated_at },
        contentBase64: row.content_base64,
      };
    },
    listFiles() {
      const rows = db
        .prepare("SELECT id, owner, name, mime, size, updated_at FROM shared_files ORDER BY updated_at DESC")
        .all() as Array<{ id: string; owner: string; name: string; mime: string; size: number; updated_at: string }>;
      return rows.map((row) => ({ id: row.id, owner: row.owner, name: row.name, mime: row.mime, size: row.size, updatedAt: row.updated_at }));
    },
    deleteFile(id) {
      return db.prepare("DELETE FROM shared_files WHERE id = ?").run(id).changes > 0;
    },
    userFileBytes(ownerUsername) {
      const row = db
        .prepare("SELECT COALESCE(SUM(size), 0) AS total FROM shared_files WHERE owner = ?")
        .get(ownerUsername) as { total: number };
      return row.total;
    },
```

```ts
function fmtBytes(n: number): string {
  if (n >= 1024 * 1024) return `${(n / (1024 * 1024)).toFixed(1)}MB`;
```

```ts
export async function fetchFileBlobText(id: string): Promise<string> {
  const res = await fetch(resolveUrl(`/api/files/${id}/content`), {
    headers: { Authorization: `Bearer ${getToken()}` },
  });
  if (!res.ok) throw new Error(`加载失败（${res.status}）`);
  return res.text();
}
```
