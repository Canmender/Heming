# M3 智能体对话实现计划（本地驱动 · 云端 IM 桥梁）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 和鸣 M3——智能体名册 CRUD、每用户本机 LLM 连接（Key 不出设备）、群内 @ 触发**本机流式生成**并经云端三事件（chunk 不入库 / finish 入库 / error）广播给全员的打字机回复。

**Architecture:** 架构红线「本地驱动，云端只是 IM 桥梁」：生成动作在发起 @ 的设备上（本地系统提示词 + 本地 Key + 直连 SSE），云端只存名册、校验成员关系、转发流与入库 finish。web 端新增 LLM 连接 store（localStorage）、openai/anthropic 双协议适配器、@ 选择器与打字机气泡；server 端新增 agents REST 与三个 WS 事件。

**Tech Stack:** 现有栈不变；无新后端依赖（SSE 在浏览器 `fetch` + `ReadableStream` 解析）。

## Global Constraints

- **架构红线（规格 §1）**：Key 只存本机 `localStorage`，任何请求不得把 `apiKey` 发往自有服务端以外的中转——即 Key 仅发给用户配置的模型供应商 baseUrl（或官方端点）；云端不配模型、不调 LLM、不存 Key；系统提示词存本地 `heming.agentPrompts`，云端 agents 表只暴露名册字段（name/avatar/description/owner），`system_prompt` 列不进任何 API。
- 规格三事件语义（§3）：`agent_chunk` 不入库仅转发；`agent_finish` 服务端校验（触发端是群成员 && agent 在群内）后入库并广播（`message_new` 附 `streamId`）；`agent_error` 不入库。
- 禁止 emoji 图标；浅灰分割线 `#e6e6e6/#ebebeb`；1.5px SVG。
- 所有新代码有 Vitest 测试；TDD；`feat:/test:/fix:/docs:` 前缀；`pnpm -r test/typecheck/build` 全绿。
- `Store` 是唯一数据接口；不动 docker 编排结构（仅 Task 9 内容重建）。
- 预设「和小鸣」（owner NULL）名册不可编辑/删除（403）。

```ts
    listAgents() { return [...agents.values()]; },
    createAgent(ownerId, body) {
      mustUser(ownerId);
      const agent: Agent = {
        id: randomUUID(), owner_id: ownerId, name: body.name,
        avatar: body.avatar ?? null, description: body.description,
      };
      agents.set(agent.id, agent);
      return agent;
    },
    updateAgent(id, ownerId, patch) {
      const cur = agents.get(id);
      if (!cur) throw new Error("agent not found");
      if (cur.owner_id === null || cur.owner_id !== ownerId) throw new Error("forbidden");
      const next: Agent = {
        ...cur,
        ...(patch.name !== undefined ? { name: patch.name } : {}),
        ...(patch.avatar !== undefined ? { avatar: patch.avatar } : {}),
        ...(patch.description !== undefined ? { description: patch.description } : {}),
      };
      agents.set(id, next);
      return next;
    },
    deleteAgent(id, ownerId) {
      const cur = agents.get(id);
      if (!cur) throw new Error("agent not found");
      if (cur.owner_id === null || cur.owner_id !== ownerId) throw new Error("forbidden");
      agents.delete(id);
      // 同时清 conversation_agents 关联（内存：conversations 值的 agentIds）
      for (const conv of conversations.values()) {
        conv.agentIds = (conv.agentIds ?? []).filter((x) => x !== id);
      }
    },
```

### Task 3: server WS 流式三事件

**Files:**

**Interfaces:**
- Consumes: Task 1 三事件、Task 2 权限（成员/agent 在群校验用既有 `store.isMember` + `listMembers`）、Task 3 前已有 `addMessage`。
- Produces: `ws.ts` 客户端事件新增分支——
  - `agent_chunk`：`isMember` 校验失败 → 回 `agent_error(code:"forbidden")` 不转发；通过则 `broadcastToConversation(event)`（原样转发给含触发者在内的全员——触发者自渲染以本地缓冲为准，收到自己的 chunk 忽略由客户端处理）
  - `agent_finish`：双重校验（`isMember` && `listMembers(conv).some(m => m.id === event.agentId && m.kind === "agent")`）失败 → `agent_error(forbidden)`；通过则 `store.addMessage(conv, "agent", event.agentId, { text: event.text }, event.replyTo ?? null)` → `broadcastToConversation({ type: "message_new", message, streamId: event.streamId })`
  - `agent_error`：校验成员后广播原事件（不入库）
  - 注意 `message_new` 现带可选 `streamId`——既有 send_message 分支广播时不带（保持 undefined）

```ts
import type { LlmProfile } from "../store/llm.js";

export interface ChatMessage { role: "system" | "user" | "assistant"; content: string }

export function buildRequest(
  profile: LlmProfile,
  messages: ChatMessage[],
  opts: { stream: boolean },
): { url: string; headers: Record<string, string>; body: string } {
  if (profile.provider === "anthropic") {
    const base = profile.baseUrl || "https://api.anthropic.com";
    return {
      url: `${base.replace(/\/$/, "")}/v1/messages`,
      headers: {
        "content-type": "application/json",
        "x-api-key": profile.apiKey,
        "anthropic-version": "2023-06-01",
      },
      body: JSON.stringify({
        model: profile.model,
        max_tokens: 1024,
        stream: opts.stream,
        temperature: profile.temperature,
        system: messages.filter((m) => m.role === "system").map((m) => m.content).join("\n") || undefined,
        messages: messages.filter((m) => m.role !== "system").map((m) => ({ role: m.role, content: m.content })),
      }),
    };
  }
  const base = profile.baseUrl || "https://api.openai.com/v1";
  return {
    url: `${base.replace(/\/$/, "")}/chat/completions`,
    headers: { "content-type": "application/json", authorization: `Bearer ${profile.apiKey}` },
    body: JSON.stringify({
      model: profile.model,
      stream: opts.stream,
      temperature: profile.temperature,
      messages,
    }),
  };
}

export async function testConnection(profile: LlmProfile): Promise<{ ok: boolean; error?: string }> {
  const req = buildRequest(profile, [{ role: "user", content: "ping" }], { stream: false });
  try {
    const res = await fetch(req.url, { method: "POST", headers: req.headers, body: req.body });
    if (!res.ok) {
      const text = await res.text().catch(() => "");
      return { ok: false, error: `HTTP ${res.status} ${text.slice(0, 200)}` };
    }
    return { ok: true };
  } catch (e) {
    return { ok: false, error: (e as Error).message };
  }
}
```

```ts
export async function streamChat(
  profile: LlmProfile,
  messages: ChatMessage[],
  opts: { signal: AbortSignal; onDelta: (text: string) => void; maxTokens?: number },
): Promise<string> {
  const req = buildRequest(profile, messages, { stream: true, maxTokens: opts.maxTokens });
  const res = await fetch(req.url, { method: "POST", headers: req.headers, body: req.body, signal: opts.signal });
  if (!res.ok) {
    const text = await res.text().catch(() => "");
    throw new Error(`provider_error: HTTP ${res.status} ${text.slice(0, 300)}`);
  }
  const ctype = res.headers.get("content-type") ?? "";

  if (!ctype.includes("event-stream")) {
    const json = (await res.json()) as {
      choices?: { message?: { content?: string } }[];
      content?: { text?: string }[];
    };
    const text = profile.provider === "anthropic"
      ? (json.content?.[0]?.text ?? "")
      : (json.choices?.[0]?.message?.content ?? "");
    if (text) opts.onDelta(text);
    return text;
  }

  const reader = res.body!.getReader();
  const decoder = new TextDecoder();
  let buffer = "";
  let acc = "";
  const handleLine = (line: string) => {
    if (!line.startsWith("data:")) return;
    const data = line.slice(5).trim();
    if (data === "[DONE]") return;
    let delta = "";
    try {
      const parsed = JSON.parse(data) as {
        choices?: { delta?: { content?: string } }[];
        delta?: { text?: string };
      };
      delta = profile.provider === "anthropic"
        ? (parsed.delta?.text ?? "")
        : (parsed.choices?.[0]?.delta?.content ?? "");
    } catch { /* 忽略非 JSON 心跳行 */ }
    if (delta) {
      acc += delta;
      opts.onDelta(delta);
    }
  };
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    buffer += decoder.decode(value, { stream: true });
    const lines = buffer.split("\n");
    buffer = lines.pop() ?? "";
    for (const line of lines) {
      if (line.trim() === "") continue;
      handleLine(line);
    }
  }
  if (buffer.trim()) handleLine(buffer.trim());
  return acc;
}
```

```ts
export interface TriggerDeps {
  getProfile: (agentId: string) => LlmProfile | undefined;
  getPrompt: (agentId: string) => string;
  fetchHistory: () => Promise<{ role: "system" | "user" | "assistant"; content: string }[]>;
  send: (e: WsClientEvent) => void;
  streamChat: typeof streamChat;
  onLocalDelta: (streamId: string, chunk: string) => void;
}

export function newStreamId(): string {
  return `${Date.now()}-${Math.random().toString(36).slice(2, 8)}`;
}

export async function runAgentMentions(
  conversationId: string,
  mentions: { agentId: string; name: string }[],
  userText: string,
  deps: TriggerDeps,
): Promise<void> {
  const history = await deps.fetchHistory();
  await Promise.all(
    mentions.map(async (m) => {
      const profile = deps.getProfile(m.agentId);
      const streamId = newStreamId();
      if (!profile) {
        deps.send({
          type: "agent_error", conversationId, agentId: m.agentId, streamId,
          code: "provider_error", message: "未绑定 LLM 连接",
        });
        return;
      }
      const messages = [
        ...history,
        { role: "user" as const, content: userText },
      ];
      const prompt = deps.getPrompt(m.agentId);
      if (prompt) messages.unshift({ role: "system" as const, content: prompt });
      let acc = "";
      try {
        await deps.streamChat(profile, messages, {
          signal: new AbortController().signal,
          onDelta: (d) => {
            acc += d;
            deps.onLocalDelta(streamId, acc);
            deps.send({ type: "agent_chunk", conversationId, agentId: m.agentId, streamId, text: d });
          },
        });
        deps.send({ type: "agent_finish", conversationId, agentId: m.agentId, streamId, text: acc });
      } catch (e) {
        const err = e as Error;
        if (acc) deps.send({ type: "agent_finish", conversationId, agentId: m.agentId, streamId, text: acc });
        deps.send({
          type: "agent_error", conversationId, agentId: m.agentId, streamId,
          code: err.name === "AbortError" ? "aborted" : "provider_error",
          message: err.message.slice(0, 300),
        });
      }
    }),
  );
}
```
