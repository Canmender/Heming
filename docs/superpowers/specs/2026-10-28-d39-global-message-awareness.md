# d.39 · 全域消息感知：后台在线、系统通知、按会话免打扰

- 日期：2026-10-28
- 相关版本：d.38.1.10.0（基线）、本 spec = d.39.1.10.0（特性位 +1）
- 上游依据：`docs/research/2026-10-28-ai-im-ux-pain-points.md`（P0/P1）
- 涉及包：`packages/web`（主）、`packages/desktop`（系统通知桥）
- 说明：不改服务端协议、不解密后台消息正文、不引入第三方依赖。

## 0. 问题（有代码证据）

| 编号 | 用户撞到的现象 | 证据 |
|---|---|---|
| A | 在主页/工作区/设置页时收不到新消息：未读不涨、通知中心不动 | WS 只在 `ChatPage` 挂载时连接；切页即卸载并 `close()`。`NavRail` 的全局未读只靠 `loadWorkspace` 刷新 |
| B | 窗口不在前台时完全无感：消息没有系统通知 | 桌面主进程只有 `voice-call:notify` 会弹 `Notification`；消息没有系统通知桥 |
| C | 群太吵时无法单独静音某个会话 | 通知中心与系统通知都没有「按会话免打扰」维度 |

## 1. 决策

### A. 后台消息通道（不解密、只做感知）

- 已登录且**当前页不是聊天页**时，由 App 壳持有第二条 WS 连接；进入聊天页时关闭，由 `ChatPage` 自己的连接接管。
- 后台只处理三件事：
  1. `message_new`（非自己发送）→ 未读 +1、`Conversation.lastMessageAt` 更新、应用内通知；
  2. `read_update`（自己）→ 未读清零、`lastReadAt` 更新；
  3. `onOpen` → `loadWorkspace()` 复核一次（补齐断档期间的未读/顺序）。
- **不解密正文**：E2E 消息的后台通知只说「有新消息」；解密仍由聊天页完成。
- 连接重叠（页面切换瞬间两条连接同时在线）由**消息 id 去重**兜底：同一条消息只计一次未读、只提醒一次。

### B. 桌面系统通知（窗口不在前台时）

- 仅桌面端：preload 暴露 `__heming_notify`（渲染层 → 主进程发通知；主进程点击 → 聚焦窗口并回传会话 id）。
- 渲染端只在 `document.hasFocus() === false` 时请求；主进程再次确认窗口未聚焦后才弹。
- **正文固定「你有一条新消息」**，标题用会话名；**不显示消息内容**（锁屏/通知中心可能被别人看到）。
- 点击通知：还原/聚焦主窗口，并打开对应会话（无会话 id 时只聚焦）。
- 浏览器环境无此桥，静默跳过（仍保留应用内通知）。

### C. 按会话免打扰

- 本机偏好键 `heming.convPrefs.v1`：`{ [convId]: { muted?: boolean } }`，不跟设备、不上云。
- 免打扰**只抑制提醒**（应用内通知 + 系统通知），**不抑制未读计数、不丢消息、不改最近活跃排序**。
- 入口：会话信息卡（标题栏「⋯」弹出）增加「免打扰」开关，`role="switch"`、`aria-checked`。
- 文案：「免打扰」/「已开启免打扰」；无 emoji，细线铃铛 SVG。

### D. 去重与边界

- `bumpUnread(convId, at?, messageId?)`：同 `messageId` 只处理一次（进程内 500 条上限，超出丢最旧）。
- 会话不在本地列表时（新会话/列表未加载）：仍然返回「这是一条新消息」以便提醒，同时触发 `loadWorkspace()`；
  未读以服务端刷新为准。
- 自己发送的消息不提醒、不涨未读。

## 2. 明确不做

- 不做完整会话列表/置顶（下一轮）。
- 不做全局消息搜索、消息收藏/置顶。
- 不做 presence（仍需先把 WS 上提 App 壳，本轮只做后台通道，不迁移聊天页的连接与解密）。
- 不做托盘常驻/任务栏角标；关闭窗口行为不变。
- 不解密后台消息正文；不把消息内容写进系统通知。
- 不改服务端 WS 协议。

## 3. 风险与处置

| 风险 | 处置 |
|---|---|
| 页面切换瞬间两条 WS 重叠 → 重复未读/提醒 | 消息 id 去重；通知中心本身按 `message:<id>` 去重 |
| 后台连接漏掉 E2E 解密 | 后台只做感知；进入聊天页后 `loadMessages` 解密补齐 |
| 系统通知泄露内容 | 正文固定；标题只显示会话名 |
| 通知太吵/打扰 | 按会话免打扰；窗口聚焦时不弹系统通知 |
| 通知点击时窗口已关/不存在 | 主进程查找可用窗口，找不到就忽略 |
| 后台连接在登录前建立 | 只在 `authUser` 存在时启用；未登录不建连 |

## 5. 验收

- 门禁：`pnpm -r build && pnpm -r --workspace-concurrency=1 test` 全绿。
- 人工复核：在主页收到消息 → 导航未读角标 +1、通知中心出现、窗口不在前台时弹系统通知；
  点通知回到对应会话；开启免打扰后不再提醒，但未读仍增长；E2E 通知不显示正文。
- 版本：`d.39.1.10.0`；CHANGELOG、HANDOFF、INDEX 同步。
