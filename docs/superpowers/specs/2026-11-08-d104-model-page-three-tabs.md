# d.104 模型页：三个分区，magpie 式的界面与动效

- 日期：2026-11-08
- 版本：`d.104.2.42.0`（特性 +1）
- 承接 d.103 的重构。

## 1. 继续收拢：三个分区

| 之前（d.103） | 现在（d.104） |
|---|---|
| 模型 / 添加来源 / 账号 / 路由 / 更多 | **模型 / 来源 / 运行** |
| 添加来源与账号分开 | 「来源」= 订阅登录 + 已登录账号 + API Key 服务商 + 自定义地址 + 已添加来源 |
| 路由与更多分开 | 「运行」= 实时链路 + 候选链入口 + 路由分组 / 用量 / 备份 / 同步 / 库 / 高级命令（全折叠） |

## 2. UI/UX 参考 magpie 的路由页

- 顶部分区改成**分段控件**（灰底胶囊 + 当前项白底浮起 + 阴影），与 magpie 顶部 Tab 同构；
- 模型/账号/来源都改成**行卡片**：头像圆点（按名称取色）、名称、说明、右侧状态；hover 抬起 200ms；
- 实时链路重做：
  - 左列客户端卡片、中间「和鸣 · 模型路由」卡片、右列账号卡片，不再是纯 SVG 线框；
  - 连线按状态着色（蓝/绿/琥珀），进行中的线以 **0.7s** 循环虚线流动（magpie 的 rtflow 节奏）；
  - 正在回答的账号行加深边框，其余行淡出；
  - 图下一句人话总结 + 右对齐大数字统计（请求 / 改道 / 失败），再下面「最近请求是怎么走的」逐条记录；
- 动效全部走 CSS：`rta-enter` 卡片 300ms ease-out 入场、`rta-hit` 200ms 抬起、
  `rta-flow` 0.7s 虚线流动、`rta-live-dot` 1.8s 呼吸点；`prefers-reduced-motion` 下全部关闭；
- 加载态：首次读取来源/账号时显示骨架条，避免「空一下再跳出来」；
- 空状态：给一张极简节点示意图 + 一句引导，不再只有一行字。

## 3. 去品牌与去运维（延续 d.103）

- 实时链路中间节点写「和鸣 · 模型路由」，不出现第三方名称；
- 仍无服务状态、地址、端口与启停按钮。
