## 1. 名册管理

### 1.1 搜索（≥5 个才出现）

- 左栏宽 240px，一两条智能体时加搜索栏只是噪音；≥5 个时出现，按**名称 + 简介**过滤
  （简介也能搜：用户记得的常是「那个写周报的」）。
- 无结果：「没有匹配的智能体」+「清空搜索」，不把空列表当成「一个智能体都没有」。
- 空名册仍走原来的「新建智能体 / 从模板创建」引导，两条路径不重叠。

### 1.2 分组

- 系统与自建同时存在时打「系统智能体 / 自建智能体」两个小标题；只有一类时不打。
- 分组标题刻意用「自建智能体」：左栏表头已经叫「我的智能体」，同名会让人以为重复渲染。

### 1.3 编辑常显

`opacity-0 group-hover:opacity-100` 的写法对鼠标党没问题，但触控板/键盘/读屏用户等于没有入口
（此前只有焦点落到按钮上才显示）。改为低对比常显 `opacity-60`，hover/focus 加深到 100，
并补 `title="编辑智能体"`。

## 2. 任务详情：未绑定提示去重

选中运行记录时中栏 = 嵌入式 ChatPage，它自己会渲染「当前智能体还没有绑定模型连接」；
右栏汇总卡也渲染同一个组件 → 同屏两遍（审计 P2-5）。现在：

| 场景 | 提示位置 |
|---|---|
| 中栏渲染 ChatPage（已聚焦会话） | 只在中栏输入区上方 |
| 中栏不是 ChatPage（如从会话快照恢复选中但未聚焦） | 右栏汇总卡 |

判定用 `activeConversationId === selected.conversationId`，与「中栏到底渲染了什么」同源。

## 3. 复制报告失败反馈

`copyTask` 原来 `ok === false` 时直接 return（无任何反馈）。现在给 `role="alert"`：
「复制失败：浏览器不允许写剪贴板。可在步骤/结果区手动选择文本复制。」5 秒后自动消失；
成功路径仍是「已复制」1.5 秒。
