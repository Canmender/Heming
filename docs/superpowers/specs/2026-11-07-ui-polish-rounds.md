## R1–R3 文案：去 AI 腔

### 问题（证据）

- 页头副标题大量「全站一个团队」「智能体管自己的记忆设置」「能力包在本机管理」「不代你执行任何操作」这类
  抽象、第三人称、解释性的句子；用户读不出「这页能干什么」。
- 同一个隐私承诺在副标题、空态、卡片里重复 2–3 遍；空态文案里出现「真实进度」等自我指涉。
- 模块卡先解释「与插件同属能力包模型」，再说能做什么；信息中枢描述里出现「stdio 拉起本机进程」这类实现细节。
- 智能体页页签右边挂一句「任务视图：运行记录、目标模板、报告与分叉都在这里」，对当前页签无意义。

### 修法

- 13 处页头副标题改写为「一句话 + 具体名词」；空态描述只保留独有信息，不复述页头；
- 模块/引导文案改成动作句；实现细节留给规格文档；删除页签噪声；
- 修掉首跑引导「0/3已完成」缺空格。

## R4–R5 按钮一致性

### 问题

- 主按钮两种写法并存：`.ui-btn.ui-btn-primary` 与手写 `rounded-lg bg-ink px-3 py-1.5 text-[12px]`；
- 危险按钮颜色两套：主题里的 `#c43d3d` 与页面手写 `#b42318`；
- 30 处次级按钮手写描边，其中「恢复默认」漏写文字颜色（存在黑底黑字风险）。

### 修法

- 主按钮 14 处、危险按钮 14 处、次级按钮 30 处全部换成语义类；
- 强调色/危险色/暗色 hover 回到单一来源，后续改主题一处生效。

## R6 页签一致性

### 问题

- 设置区 / 记忆区 / 插件区是下划线 Tab；智能体页 / 团队页是「黑色药丸」Tab——同一层级的切换出现两种视觉语言。

### 修法

- 新增 `lib/ui/tabStyles.ts`（`PAGE_TABLIST` / `pageTabClass`），五个页面统一为下划线式；
- 说明边界：页内二级筛选（团队「全部/任务/日程」、信息中枢「检索/日程」）是工具栏分段控件，保持紧凑按钮。

## R7 记忆区：宽屏行宽与召回文案

### 问题

- 1600 宽屏下记忆区卡片宽 1256px，表格列被拉得很开；标签与正文也没有和内容列对齐；
- 召回相关说明是「实现文档」口吻：「本机最近 40 次『带记忆的生成』留档……判据是词重合，不是模型自述」、
  「总量受 1200 字符预算约束」、「累计的注入/引用次数还用于个性化加权（……最多提权 25%）」。

### 修法

- 标签、正文统一收进 1200px 居中列（与设置区同一做法，`mx-auto max-w-[1200px]`）；
- 召回记录 / 召回预览 / 复盘 / 自动记忆 / 数据库说明改成短句，只留用户需要的结论：
  「本机最近 40 次召回的记录：注入了哪几条、哪些被预算截掉、回答可能用到了哪条。只存本机，不参与导出；
  被引用多的记忆会略微加权。」；空态改「还没有记录。开着记忆时，在聊天里 @ 智能体说话就会留档。」。

## R8 团队页：共享条收敛

### 问题

- 一条横栏里塞了：一段 40 字说明 + 3 个复选框 + 「尚未同步」 + 「清除我的共享记录」，在 1280 下换行后很难扫读；
- 一项共享都没开时仍显示「尚未同步」，容易被读成同步故障。

### 修法

- 说明改成「对团队可见：任务 / 日程摘要与用量排行，不含对话和工具参数」；
- 3 个复选框收进 `role="group"`，间距统一；
- 只在 `shareCount > 0` 时显示同步状态；
- 「清除我的共享记录」改为次级按钮「清除共享记录」，与其它页面按钮同一档。

## R9 首页：统计口径与资讯文案

- 「今日动向」副标题「最近 100 条内」是实现口径（还容易被读成只统计 100 条），改为「今天的团队动态」；
- 首页「最新资讯」三条摘要各 50–70 字、且重复同一段隐私声明，压到一句；标题保留（测试也锁标题）。

## R10 键盘习惯：回车提交

### 问题（真实浏览器实测）

- 自动化「新建/编辑」弹窗不是 `<form>`：在名称里按 Enter 什么都不发生；
- 设置区搜索框输入关键词后按 Enter 也不跳转，必须把鼠标移到结果上；
- 智能体新建弹窗、设置昵称本来就有 `<form>`，回车可用——三处行为不一致。

### 修法

- 自动化弹窗改为 `<form onSubmit>`，保存按钮 `type="submit"`（Esc 仍由 useModalA11y 关闭）；
- 设置搜索框 `onKeyDown` 捕获 Enter → `jumpToCard(results[0])`，提示文案补「Enter 打开第一项」；
- 实测：自动化弹窗回车落库并关闭、设置搜索回车切到目标分区、昵称回车显示「已保存」。

## R11 设置区卡片宽度

- 「模型」页 5 张卡带 `max-w-[520px]`，同页其它卡与「外观」页都是内容列全宽（760），宽屏下一半页面半宽、一半全宽；
- 去掉 5 处 520 限制，统一跟内容列；模型页卡片从 517px → 760px。

## R12 删除重复的「生效说明」

- 「改动即时生效，仅作用于本机，无需重启」在设置区页头副标题已写一遍，又被 7 张卡片各写一遍；
- 删除 SettingsPage / LlmSettingsCard / HitlPolicyCard / RouteGroupsCard 的重复注脚与常量，
  并去掉 FileEditCard / ContextSettingsCard 句尾重复；同步删掉两条只断言这句话的用例。

## 每轮验证口径

- 单测：改动涉及的页面/组件用例 + 全量 web 套件；
- 真实浏览器：headless Edge + CDP（脚本在 `.tmp/d7x/`，不入库），1600×1000 为主、必要时 1280/1024；
- 视觉断言用截图人工复核 + DOM 断言（按钮高度、Tab class、文案存在性）；
- 门禁：`pnpm -r build` / `pnpm -r --workspace-concurrency=1 test` / `pnpm -r typecheck`。
