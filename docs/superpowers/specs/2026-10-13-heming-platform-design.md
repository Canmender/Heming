# 和鸣设计文档

- 日期：2026-10-13
- 状态：已与用户逐节确认
- 参考项目：D:\MultiAgent（合鸣 Ensemble）——全新项目、借鉴其成熟架构，不复用代码

## 1. 概述

原生电脑端智能体应用平台，由**云端服务器**与**桌面端（Electron）**构成，包含 IM 即时通讯模块与多 Agent 混合框架。定位：个人智能体工作台——与人类/智能体聊天协作，管理模型接口、工具接口与记忆知识库。

### 1.1 范围与分期

- **MVP（一期）**：账号体系、好友/通讯录、1:1 与群聊（含预设混合群、纯 Agent 群）、内建智能体创建与对话、@提及、已读回执、共享文件库与右栏投递、个人 LLM 配置。
- **二期**：记忆区/知识库（本地 RAG）、MCP 接口区、外部 harness 桥接（Claude Code / OpenCode 等）、语音/表情/消息转发、Token 用量统计完整版。

### 1.2 核心决策（已确认）

| 决策 | 结论 |
|---|---|
| 与 MultiAgent 关系 | 全新项目，借鉴架构与技术栈，不搬代码 |
| 部署形态 | 云端中心化：桌面端是薄客户端，数据以云端为准 |
| 数据边界 | 云端仅存：账号/好友/智能体元数据/消息/显式共享文件。桌面端本地存：LLM Key、MCP 配置、记忆、知识库、本地工作目录文件、消息缓存 |
| LLM 调用 | 桌面端直连模型供应商（个人 Key），云端不代理推理、不存明文 Key |
| 记忆/知识库 | 本地（个人设置、独立运行），不上传云端 |
| 智能体形态 | 内建 LLM 智能体为主，二期支持外部 harness 桥接（桌面端本机执行） |
| 接口区含义 | MCP/工具接口管理（LLM 配置在通讯录内按智能体/个人设置） |
| 记忆区含义 | 全局记忆 + 知识库（本地，二期） |
| 左栏显隐 | 进入会话/内容后左栏完全隐藏，按钮/快捷键（⌘\）呼出 |
| 右栏用途 | 文件浏览与投递（云端共享 + 本地绑定目录） |
| 技术栈 | Electron + React 18 + TS + Tailwind + Zustand；服务端 Express 5 + WS + SQLite(WAL)；pnpm monorepo |

## 2. 总体架构

```
┌──────────────────────────────────────────────────────┐
│                桌面端 (Electron)                       │
│  React UI + harness 桥接 + 个人数据全在本地             │
│   · LLM 直连（个人 API Key，存系统钥匙串）              │
│   · MCP 服务器按个人配置在本机启动（二期）               │
│   · 个人记忆库 + 知识库（本地 SQLite + 向量，二期）      │
│   · 本地工作目录文件不上传                              │
└──────────────┬───────────────────────────────────────┘
               │ HTTPS REST + WebSocket（token 鉴权）
┌──────────────▼───────────────────────────────────────┐
│              云端服务器 (Node.js)                      │
│  IM 服务 │ 通讯录/智能体元数据 │ 显式共享文件库          │
│  SQLite (WAL)                                          │
│  —— 不存记忆/知识库/Key/本地文件，不代理 LLM ——          │
└──────────────────────────────────────────────────────┘
```

**语义后果（已知并接受）**：智能体记忆在创建者本机，换设备不跟随；混合群里智能体的回复由发起 @ 的成员桌面端生成，以 `sender_type=agent` 经云端广播。

## 3. 数据模型

### 3.1 云端（SQLite，按用户隔离）

| 表 | 关键字段 | 说明 |
|---|---|---|
| `users` | id, username, password_hash, display_name, avatar | 账号 |
| `friendships` | user_id, friend_id, status(pending/accepted) | 好友关系 |
| `agents` | id, owner_id, name, avatar, description, system_prompt, model_hint, visibility | 智能体**元数据**（人设在云端供可见可拉群；模型/记忆不在云端） |
| `conversations` | id, type(direct/group), preset_flag | 会话；预设混合群 `preset_flag=1`，服务端播种 |
| `conversation_members` | conversation_id, user_id, role(owner/admin/member) | 群成员（人类与智能体统一入表） |
| `messages` | id, conversation_id, sender_type(user/agent), sender_id, payload(JSON), reply_to, created_at | 消息：文本/文件引用/系统事件 |
| `message_reads` | message_id, user_id, read_at | 已读回执 |
| `shared_files` | id, owner_id, name, blob, mime, size, scope | **仅显式共享**的文件（右栏「云端共享」）（口径：登录可见，DELETE 属主校验；会话级 ACL 留后续） |

### 3.2 桌面端本地（SQLite + 系统钥匙串）

| 表 | 说明 |
|---|---|
| `llm_configs` / `mcp_servers` | 个人模型接入与 MCP 配置；API Key 存系统钥匙串，不进库 |
| `agent_memories` | 全局 + 按智能体记忆（二期） |
| `knowledge_docs` + 分块/向量 | 本地知识库（二期） |
| `workspaces` | 本地工作目录绑定（仅存路径） |
| `message_cache` | 消息本地缓存（加速/离线可读，云端为准） |

**智能体归属**：个人创建（owner_id），元数据云端共享、可拉入任意群；记忆/知识库/Key 归创建者本机。

## 4. IM 模块

- **链路**：鉴权 WebSocket 长连接做实时推送（新消息/已读/在线/群变更）；REST 做历史拉取与管理操作。
- **会话类型**：人类 1:1；纯人类群；纯 Agent 群（头脑风暴，用户自建）；预设混合群（服务端播种，不可自建）。
- **智能体回复语义**：发起 @ 的用户桌面端拉起该智能体（本地人设 + 本地记忆 + 本地 Key），流式生成后以 agent 身份经云端广播；群成员并行 @ 不同智能体互不阻塞。
- **MVP 消息能力**：文本、文件（引用共享库）、@提及、回复引用、已读回执、撤回。语音/表情/转发放二期。
- **安全**：WS token 鉴权；入库前 Zod 校验；按群成员关系过滤投递。

## 5. 通讯录与工作区

- **通讯录**：人类好友与我的智能体混排；搜索、加好友（申请/同意）、创建/编辑/删除智能体、模型设置（添加供应商 Anthropic/OpenAI 兼容/DeepSeek/Ollama/自定义端点、API Key、连通性测试）。雷达点头像进联系人详情页；其余头像滚入右侧分组竖列（群聊/人类/智能体）。
- **创建智能体**：名称、头像、简介、系统提示词、绑定 LLM（个人模型列表选择 + 温度等参数覆盖）、加入自己创建的群聊（新建群时勾选，入群后即可被 @）、可选挂载本地知识库/记忆作用域（二期）。
- **工作区**：会话列表分组——直聊 / 群聊（纯人类 / 预设混合 / 我创建的 Agent 群）。新建纯 Agent 群：命名 → 从通讯录勾选智能体 → 开聊。
- **主页（v7 七区，真实数据优先）**：① 问候行——问候 + 日期 + 两个小徽标（「版本 v0.1.0」静态、「今日已用 {当天 total}」读本地日志实时计算）+ 欢迎文案「欢迎使用和鸣」；② 四张统计卡——会话总数（直聊）/ 好友数（可拉群聊）/ 我的智能体（M3 前恒 0）/ Token 用量（月度汇总卡）；③ 两栏左：最近会话——取前 6 条，行内为头像 + 对方名 + 最新一条预览（消息未加载显示「暂无消息」）+ 时间，**M1 无未读计数、不显示未读角标**，空态「暂无会话，从工作区开始」；④ 右栏上：智能体动态——M1 空态行「M3 创建智能体后，动态显示在这里」；⑤ 右栏中：待处理——真实好友申请列表，带「接受」按钮（成功后刷新工作区，失败 console.warn）；⑥ 右栏下：系统状态三行——云端连接（挂载时 `GET /api/health` 探测，正常/失败）、实时通道（首页未连 ws，中性文案「会话内连接」，不假报已连接）、本地工作目录（M4 前恒「未绑定」）；⑦ 底部通栏：最新资讯——三张**静态**产品介绍卡（来源标签 官方/教程/技巧 + 标题 + 摘要 + 日期，硬编码常量，非虚构统计数据）。Token 卡内置可点切换三视图：**个人**（当月配额进度 + 按模型明细）/ **团队**（成员排行）/ **按日期**（当月全日期表格，零值天不跳过，行可点击展开当日按模型明细）。统计口径：本地只存逐条原始调用日志（模型、tokens、时间），**不存跨天累计总值，每次读取按当天/当月重新计算**。MVP 仅实现个人视图；团队与按日期的跨端汇总（如团队视图）二期做（需服务端汇总）。
- **导航占位**：MVP 中「接口区」「记忆区」入口存在，页面为「二期开放」占位页，不可点进子功能。

## 6. UI 布局与视觉规范

**三栏布局**：

- 左导航（**A 方案：图标轨 + 悬停浮签**）：约 54px 图标轨常驻左缘——5 个图标按钮（主页 / 工作区 / 接口区 / 记忆区 / 设置区，34×34、选中态黑底反白）+ 底部圆形头像（点击退出登录，aria-label「退出登录」；悬停浮签仍显示「{displayName} · 在线」）；悬停时右侧滑出黑色胶囊浮签（名称 + 快捷键徽标，如「主页 Alt1」，150ms 淡入 + 轻微左移），**无产品名文字**；快捷键 **Alt1–Alt5 直接切页**（输入框聚焦或未登录时静默忽略，避免与浏览器/输入法组合键冲突）。进入会话导航**完全隐藏**，左缘留 6–10px 呼出窄条（顶部 chevron 按钮 + 快捷键 ⌘\ / Ctrl+\）点击展开回图标轨。
- 中部视图区：主页总览或全屏对话。
- 右栏目录区：上「云端共享」、下「本地工作目录」，**VS Code 资源管理器式紧凑文件树**——小箭头点击展开/收起文件夹、缩进层级、紧凑行高。

**文件投递**（文件行 hover 操作）：发送到会话（云端共享直接引用；本地文件显式上传后引用）；作为智能体上下文（云端文件由云端注入，本地文件由我的桌面端注入，他人不可见时降级提示文件名）；预览（文本/图片/Markdown 内嵌，其他提示下载）。本地文件永不自动上传。

**视觉**（浏览器视觉稿已定稿）：

- 主体白色；卡片带灰色柔投影（厚重悬浮层次）；
- **分割线/边框用浅灰 #e6e6e6 一档，不用纯黑**；纯黑仅作文字与小面积强调（选中段按钮、时间线圆点）；
- **不用 emoji 图标**，统一细线 SVG 图标（1.5px stroke）；
- 选中项：浅灰描边 + 偏移柔阴影的「悬浮」态；
- **界面 chrome 不显示产品名**：产品名「和鸣」仅出现在窗口标题与登录页 h1，导航/壳层等界面 chrome 不出现产品名文字（主页欢迎文案属内容区，允许出现）。

## 7. 错误处理

| 场景 | 行为 |
|---|---|
| WS 断连 | 指数退避自动重连，顶部细条提示，恢复后拉断档消息 |
| LLM 调用失败 | 气泡位错误卡（原因 + 重试），不吞错误 |
| 本地路径失效 | 目录树失效态，引导重新绑定 |
| 生成中 | 流式打字态，可中断（撤回/@ 切换） |
| 发送失败 | 气泡「未发送」标记，点击重发 |
| 401 | 跳登录页，本地数据保留 |

## 8. 测试策略（Vitest）

- `shared`：Zod schema 边界用例（消息/事件/文件引用）。
- `server`：REST/WS 集成测试——注册登录、好友、会话、消息投递过滤、已读回执、共享文件权限。
- `web`：会话切换、导航显隐、@提及解析等核心交互单测 + 关键页面组件测试。
- `desktop`：harness 桥接进程管理单测（二期）。
