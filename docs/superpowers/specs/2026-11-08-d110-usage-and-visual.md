## 2. 用量面板（新增）

数据来自内核自己的记账接口（与 magpie 用量页同源）：

- `GET /v1/magpie/usage?period=today|7d|30d|all`：概览 + 每日 series + 按 Agent/模型/账号拆分；
- `GET /v1/magpie/usage/requests?period=&limit=`：最近请求明细。

页面（运行分区内）：

- 概览卡：请求数（含失败数）、输入/输出 token 合计、费用（含未定价条数）、缓存读 token；
- 每日柱状图：请求数 / Token 可切换，SVG 柱状 + hover 提示 + 抽稀日期标签；
- 拆分：按模型 / Agent / 账号，行内进度条 + 调用数/token/费用；
- 最近请求表：时间、Agent、请求模型、输入/输出 token、耗时、状态；
- 导出 CSV：调用模型服务的 `usage --csv`（结果落既有输出面板）；
- 空态 / 读取失败都有明确提示，不画空图。

## 3. 与 magpie 原版的功能差距（更新）

本轮把「用量可视化」从命令输出升级成原版同级的面板；仍未做：

- Agent 模型改写（改本机 Claude Code/Codex 等配置）；
- 分组规则编辑器（token/意图/文件夹/时段/嵌套组）、自动组；
- Provider 高级字段表单（fallback、多 Key 策略、headers、余额）；
- 上下文分析（请求体留存与隐私边界需先设计）；
- 网关密钥/局域网共享/配额告警、Library 编辑、会话/启动器、托盘/网页版入口。
