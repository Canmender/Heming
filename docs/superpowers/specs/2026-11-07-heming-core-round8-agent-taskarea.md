## 2. 为什么用「登记表」而不是全局状态

把 ChatPage 的 `runsRef`（每个会话一组 AbortController）上提成全局 store，会带来两个后果：
流生命周期跨页面泄漏、以及 ChatPage 卸载后仍能被外部中断（对已销毁组件调用）。登记表只登记
**当前挂载**的实例，卸载即注销，语义与「谁能停这个会话」严格对齐；调用方拿到布尔值就知道
「这条运行现在在不在能被停的位置」，可以如实提示而不是假装停掉。
