# d.60 · 用户体验优化轮（规格）

- 日期：2026-11-02
- 状态：**本轮实施**
- 触发：用户「继续优化用户体验」
- 证据：`.tmp/ux/before/*.png`（13 张真实流程截图：登录 / 首跑主页 / 智能体空态与对话 / 设置五分区 / 命令面板 / 通知中心 / 团队动向与用量 / 任务区），以及 `research/2026-10-28-ai-im-ux-pain-points.md`、`research/2026-11-02-a11y-error-audit.md`。
- 红线不变：本地驱动、E2E 不降级、个人数据不出设备、HITL 不做「全部放行」。

## 1. 审计到的问题（截图 + 代码依据）

| # | 问题 | 证据 |
|---|---|---|
| U1 | **首跑没有任何「下一步」引导**：模型未配置时，主页只有统计卡与资讯，用户不知道要先去配模型 | `02-home-firstrun.png`：Token 用量 0 / 「暂无调用记录」；无连接入口 |

## 2. 本轮做（三轨）

### A. 首跑引导与「未绑定模型」提示统一（U1/U2）
- 主页：当**没有任何模型连接**时，顶部显示「开始使用」卡（3 步：配置模型连接 → 和智能体对话 → 建第一个任务），每步带按钮与完成勾选；全部完成或用户手动关闭后不再出现（本机 `heming.onboarding.v1`，只存本机、不上云）。三步骤状态均为**真实状态派生**（连接数 / 会话数 / 任务数），不是硬编码。
- 对话页：选中智能体但未绑定 LLM 时，输入区上方显示统一提示条「当前智能体还没有绑定模型连接」+「去设置」，并禁用发送（附 `title`/`aria-describedby` 说明），不再等到发送才报错。
- 任务区：复用同一个提示组件与文案口径（现在是各写一句）。
- 验收：三处提示同源（一个组件/一个 hook）；新增用例覆盖「未绑定→提示出现、绑定后消失、禁用发送不产生请求、主页引导三态与关闭持久化」。

### B. 命令面板 v2（U3）
- 空查询时展示**分组**：最近使用（本机记录 ≤5）、页面跳转（13 个导航页，带 Alt 快捷键标注）、常用动作（新建任务 / 新建智能体 / 打开通知中心 / 打开设置 / 切换主题?（若已有））。
- 输入时同屏检索：页面名、页面描述、设置分区名、动作名、成员、技能、归档（已连接时）；分组展示、组间不混排。
- 键盘完整：↑↓ 移动、Enter 执行、Esc 关闭、Tab 不大跳；结果项有 `role="option"` 与 `aria-selected`（外部输入框用 `aria-activedescendant` 或保持现有 a11y 口径）。
- 动作执行走既有 store（`useUiStore` 切页、任务草稿、智能体新建弹窗等），**不新增 IPC、不引入新依赖**。
- 验收：新增用例覆盖「页面检索命中」「动作执行」「最近使用落盘/淘汰」「空查询分组」「键盘导航」；不破坏现有成员/技能/归档结果。

### C. 空态与细节打磨（U4/U5/U6/U7）
- 对话空态：增加 3 条可点击的示例提示（点击填入输入框、不自动发送）；示例按当前智能体能力（是否绑定视觉/工具）挑选，**不发请求**。
- 输入区旁显示快捷键提示（Enter 发送 / Shift+Enter 换行 / Esc 停止），首次使用后仍常驻但弱化。
- `PageFallback`：改成与页面结构相近的骨架（左栏 + 内容块），保留 `data-testid="page-fallback"`（d39 用例依赖它）。
- 登录页：装饰圆环改为**不穿过表单卡片**（只在右侧/背后，必要时降低不透明度）；只改布局与层级，不改品牌字样。
- 右侧文件栏：加标题「共享文件」，空态一句「还没有文件；在输入框上传或从工作区绑定」；按钮文案保持短（`title` 补全）。
- 验收：骨架有测试锚点且不遮挡交互；登录页不出现圆环压字；文件栏空态文案；空态示例点击只填不发送（用例断言无请求）。

## 3. 明确不做
- 不改导航结构、不加新页面；不做全局消息/任务/记忆全文检索（另立规格）；不改主题系统与设计 token；不动安全红线相关 UI（HITL 文案、E2E 状态）。
- 不做移动端适配；不引入动画库。

## 4. 验收与发布
- 门槛：三轨定向用例全绿 + `tsc --noEmit` + `pnpm -r build`；发布前跑全量门禁（逐包，允许单包重试一次）。
- 视觉：用 `.tmp/ux-capture.mjs` 重截同一批流程（修复 Escape 关闭命令面板的注入方式），与 `.tmp/ux/before` 对照。
- 版本：体验优化归 fix/feature 混合 → 至少 `d.60.2.22.0`（特性 +1：命令面板能力升级；若只做打磨则 `d.59.2.22.0`），发布时按实际落地项定。
