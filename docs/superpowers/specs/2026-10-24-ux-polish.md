# d.35.1.9.0 · 全量自检后的体验修补

- 日期：2026-10-24
- 相关版本：d.35.1.8.0（基线）、本 spec = **d.35.1.9.0（修订位 +1）**
- 上游依据：`docs/research/2026-10-22-deep-audit-followup-plan.md` §4（P2 体感缺口剩余项）+ 本轮三路只读勘察
- 涉及包：`packages/web`（主）、少量 `packages/shared` 类型
- 说明：**不占用 d.36**。d.36 仍按计划留给 P0-5 `safeStorage`（`specs/2026-10-23-d36-safestorage.md`）；本轮只修体感缺口，不触碰安全红线。

## 0. 这一轮要解决什么

全量门禁（build / typecheck / test）已全绿，问题集中在「用户当天就会撞到、但测试没覆盖」的体感层：

1. **聊天页把失败伪装成空**：历史拉取失败与「真的没有消息」长得一样，没有加载态，也没有重试入口。
2. **常用操作缺失**：没有时间戳、没有整条复制、图片点不开、粘贴截图无反应、滚动不跟手、中断后显示英文 `AbortError`。
3. **设置与工具页的反馈不完整**：提交中可以 Esc 关掉弹窗、清空授权无确认无反馈、异步按钮可重复点、破坏性按钮颜色不一致。
4. **导航层的未读与提示不可信**：读完会话角标不清零、新消息不涨、横向标签无未读、通知面板被窗口裁掉、点头像直接登出无确认。

## 2. 决策（本轮做什么 / 不做什么）

### A. 聊天主界面

- **A1 历史三态**：`store/chat.ts` 增加 `messagesLoading` / `messagesError`（按 convId）。
  `loadMessages` 自己吞异常并落错误（不再 unhandled）；ChatPage 在首屏渲染骨架，
  失败渲染「加载失败：原因」+「重试」，只有「加载成功且为空」才显示现有空态。
- **A2 中断文案**：中断收口正文固定为「已中断，可继续生成」；错误行动作从「重试」改为「继续生成」。
  不改变已有的 partial 保留语义。
- **A3 滚动**：记录 `atBottom`（距底 <80px）。贴底时新消息与流式文本继续跟随；
  用户上滑后不再强行拽底，改为右下角浮动「↓ 新消息」；切会话强制到底。
- **A4 时间**：新增 `lib/formatTime.ts`，抽出 HomePage 既有 `fmtTime` 复用；
  气泡显示 `HH:mm`（跨天带日期），相邻消息间隔超过 5 分钟或跨天插入日期分隔。
- **A5 整条复制**：气泡操作条增加「复制」，复制纯文本；`clipboard` + `execCommand` 兜底，
  完成后短暂显示「已复制」。
- **A6 图片放大**：附件图片可点击打开 lightbox（遮罩 + 原图 + Esc/点遮罩关闭，复用 `useModalA11y` 或等价焦点管理）。
- **A7 粘贴/拖拽**：输入框 `onPaste` 取 `clipboardData.files`；消息区 `onDragOver/onDrop` 拖入即上传；
  复用 `sendFile` 已有的 6MB 与类型校验，不重复实现。
- **A8 上传中**：新增 `uploading` 状态，进行中禁用图片/文件/语音/发送四个入口并提示「上传中…（≤6MB）」；
  按钮 title 补上限说明。
- **A9 发送失败**：状态行区分 `info` / `error`；错误用红色 `role="alert"` + 「重试」，
  重试仅对纯文本发送可用（附件场景不提供，避免重放上传）；info 3 秒自动消失。
- **A10 键盘**：无浮层且无草稿时 `Escape` 停止生成；空草稿发送按钮 `disabled` 并降透明度。
- **A11 可达性**：气泡操作条 `group-focus-within` 可见；textarea 加 `aria-label`；
  `MentionPicker` 支持 ↑/↓/Enter/Esc 键盘选择。**不加**消息列表 `aria-live`（流式每帧播报是噪音）。
- **A12 未读准确**：`read_update` 且 `userId === 我` → 该会话未读清零；
  `message_new` 且不是当前会话、不是自己发的 → 未读 +1。`loadWorkspace` 仍是权威刷新。

### B. 设置与工具页

- **B1**：`pending` 时 Esc/遮罩不再关闭弹窗；标题旁显示「提交中…」。
- **B2**：「清空本会话授权」走 `ConfirmDialog`，说明「已授权工具将重新逐一询问」，完成后 `role="status"` 提示条数。
- **B3**：技能卡片操作区常显但弱化（不再 `opacity-0`）；搜索框提到页头并作用于分组视图。
- **B4**：测试连接 / 连接工具 / 执行工具 / 刷新注册表 按钮 `disabled={busy}` + 进行中文案。
- **B5**：存储卡「重新检测」先让「检测中…」渲染（`requestAnimationFrame` / `setTimeout 0`）再探测；
  不改探测算法。
- **B6**：设置卡底部统一一句生效说明；保存类给「已保存」`role="status"`。
- **B7**：「确认删除」统一 `bg-[#b42318]`。
- **B8**：`icons.tsx` 补 `XIcon` / `ChevronIcon`（若缺），把「＋ × ✕ ▾」替换为细线 SVG。
- **B9**：保留天数提示改为 `{kind, text}`，校验失败用错误色。
- **B10**：主题色输入改受控（本地 state 同步 store），恢复默认时刷新输入框。

### C. 导航与状态

- **C1**：通知面板改为向上展开（`bottom-0`），修复被窗口裁掉；面板内滚动保留。
- **C2**：横向标签栏补未读角标（数字，`aria-label` 带「N 条未读」）。
- **C3**：头像点击改为 `ConfirmDialog` 二次确认退出；tip 去掉硬编码「在线」。
- **C4**：通讯录与归档接入 `workspaceReady/workspaceError`，失败给「加载失败 + 重试」；
  通讯录搜索无结果给一行「没有匹配「x」的联系人」+ 清除。
- **C5**：导航轨加搜索按钮（浮签 `Ctrl K`）；命令面板 Esc 挂到面板容器；结果超上限提示「还有 N 条」。

### 明确不做（留给后续轮次）

- 真实 presence（P2-5）：需要服务端 `presence` 接口 + WS 广播，单独规格。
- 「@我」角标（P2-7）：涉及 E2E 密文里 mentions 的计数值，需先定载荷形状。
- 全部破坏性操作的 undo/回收站：需要统一的软删层，单独规格。
- 好友拒绝/群成员管理（P2-6）：涉及 E2E 群密钥重协商，按计划先出安全规格。
- WS 连接上提 AppShell：会牵动 E2E 解密 handler 与流式归属，不在本轮。
- 不引第三方依赖（虚拟列表、lightbox 库等），保持现有手写模式。

## 4. 验收

- 每条改动至少补 1 个行为用例（纯前端行为，沿用现有 `scrollIntoView` / `clipboard` mock 手法）。
- 三路各自跑通：`pnpm --filter @heming/web typecheck` + 相关测试文件 + 全量 `pnpm --filter @heming/web test`。
- 主控合并后跑全量门禁（build / typecheck / 四个包 test），再 bump 版本、更新 CHANGELOG 与 HANDOFF。
- 人工复核清单：断网进会话看骨架与重试；上滑后新消息不拽底；粘贴截图；发送失败重试；设置页四个异步按钮；
  导航轨点通知铃铛面板完整可见；点头像有确认。
