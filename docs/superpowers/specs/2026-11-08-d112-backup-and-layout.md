# d.112 页面化备份与恢复 + 布局优化

- 日期：2026-11-08
- 版本：`d.112.3.44.0`（特性 +1）
- 承接 d.111。

## 1. 备份与恢复（页面化）

之前备份/恢复只能在终端里敲命令。现在「运行」页里是一个完整面板：

- **备份列表**：应用自己的备份目录（`userData/model-backups`），显示文件名、时间、大小；
- **新建备份**：生成 `model-<时间>.backup`，在页面里的交互面板执行；口令只在该面板内存里输入；
- **恢复**：列表里点「恢复」或「从文件恢复…」（系统文件选择器）→ **二次确认** → 交互面板输入口令；
- 命令输出逐块显示（含提示语），完成后自动刷新列表；关闭面板会终止未完成的命令。

实现：

- 主进程新增 `magpie:cli:begin`（立刻返回 runId）、`magpie:backup:info`、`magpie:backup:pick` 三个通道，
  全部登记 `TRUSTED_CHANNELS`；preload 暴露 `cliBegin/backupInfo/backupPick`；
- 命令桥新增 `exit` 事件（页面能显示「完成/失败」并刷新）；
- 新组件 `model/SectionCard`（统一卡片头）、`model/ConsolePanel`（交互式命令面板）、
  `model/BackupPanel`（备份列表与流程）。

## 2. 布局优化

- 「来源」页：四张卡（订阅与账号 / API Key 服务商 / 自定义地址 / 已添加来源）改为宽屏两列，
  窄屏单列；
- 「运行」页：实时链路、用量保持通栏；路由分组通栏；多机同步/资源库与搜索/高级命令两列排布，
  备份面板独立成块；
- 统一卡片圆角 20px、内边距 16px、标题/说明/动作的排版（`SectionCard`），减少各分区漂移。

## 3. 验证

- `BackupPanel` 4 例：列表、二次确认 + 交互命令 + 输出、新建备份文件路径与刷新、无桥禁用；
- `magpie-wiring` 守卫扩展到 13 个方法 / 8 个通道（含备份与 begin）；
- 全量 web 与 desktop 门禁见发版记录。
