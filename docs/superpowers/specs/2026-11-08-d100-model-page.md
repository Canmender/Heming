# d.100 导航栏新增「模型」页：把 magpie 的管理面完整搬进和鸣

- 日期：2026-11-08
- 版本：`d.100.2.42.0`（特性 +1）
- 范围：只做模型相关（内核管理面 + 页面），不涉及信息采集等其它能力。

## 1. 为什么

d.97 之前模型内核已经内置，但和鸣的界面只暴露了「网关地址 + 模型目录」；
magpie 真正的能力（供应商、订阅账号、分组路由、用量、库、备份、多机同步）都只在 CLI/网页版里。
用户要求：**导航栏单独一个模型页，完整复刻 magpie 的功能。**

## 2. 架构：页面 → 命令桥 → 我们自己的内核

```
ModelPage（导航「模型」）
  └─ lib/magpieCli.ts（渲染层封装 / 输出解析）
       └─ preload __heming_magpie.cli / cliStart / cliInput / cliKill / openTerminal / onCli
            └─ 主进程 magpie-cli.js（白名单 + 无 shell + 流式 + 超时）
                 └─ 内核 magpie-core.exe（vendored magpie 源码编译，d.97）
```

为什么调 CLI 而不是重写：这些能力的唯一实现就是内核；重写必然两套口径，
且上游新增命令/协议时页面自动跟上。

## 3. 页面能力（九个分区）

| 分区 | 能力 |
|---|---|
| 概览 | 网关状态/版本/模型数、启动或重连、刷新模型目录、供应商/账号快查 |
| 供应商 | 列表（ID/类型/主机/模型数）、加预置（只要 Key）、加自定义 OpenAI 兼容端点（url/key/models）、详情/模型/测试/删除 |
| 订阅账号 | `accounts --json` 表格（类别/账号/额度）；Claude、ChatGPT/Codex、Gemini、Antigravity、Copilot 一键在真终端登录 |
| 分组路由 | 分组列表/详情/删除；新建或修改（名称、模型列表、smart/order/rotate/usage/pace/weight/free/fast/cheap/drain/expiring） |
| 模型 | `models` 列表；模型显示名、思考档、协议（chat/responses/anthropic/gemini/auto） |
| 用量 | today/7d/30d/all 账本与 CSV 导出 |
| 备份与同步 | 加密备份/恢复（真终端输入口令）；WebDAV / S3 / GitHub 的 now/on/off/set |
| 库与搜索 | 库状态、同步到各 agent、指令/MCP/技能；网页搜索源增删查 |
| 终端 | 白名单命令直跑，流式输出、stdin 输入、取消——覆盖页面尚未表单化的全部管理命令 |

浏览器端没有命令桥：页面降级为只读（网关状态 + 模型目录），写操作提示「仅桌面端可用」。

## 4. 安全边界

- 主进程白名单：`providers/presets/provider/import/models/model/visible/search/groups/group/accounts/library/backup/restore/webdav/s3/github/usage/settings/profiles/save/use/rename/rm/ls`；
  `uninstall`、`serve`、`tui`、`web`、`autostart` 与 agent 改写等拒绝；
- 参数按数组传给 `spawn`，**不经过 shell**；参数长度/含 NUL 有上限；
- 交互式登录与备份口令走**真终端窗口**（`cmd /c start`，命令串只允许安全字符），口令/验证码不进入页面状态；
- 输出里的 ANSI 控制符在展示前剥离；长输出只保留尾部；
- 命令桥只在桌面端存在，通道全部登记在 `TRUSTED_CHANNELS`，只由主窗口调用。

## 6. 边界与未做

- 浏览器端只读（内核命令需要本地进程，云端网页无法直接管理）；
- OAuth 登录必须由用户在本机终端完成（这是安全边界，不是缺陷）；
- 页面只覆盖常用参数；`provider set` 的高级字段、`visible` 精细规则、`settings` 全量项等仍走「终端」分区；
- 危险操作（删除供应商/分组、卸载 agent 配置）**没有二次确认弹窗**，当前依赖用户明确点击；后续可补。
