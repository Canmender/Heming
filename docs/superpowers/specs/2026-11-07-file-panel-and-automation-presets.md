# 文件管理收进智能体页 + 自动化预设（d.76.2.40.0）

日期：2026-11-07

## 1. 文件管理只保留在智能体对话页

### 问题

「共享文件」右栏从 d.67 起挂在全局 AppShell 上，所有页面常驻 240px（可拖到 420）：
主页/设置/记忆这类长页面被压窄，而除智能体页外的页面几乎没有「把文件发进对话」的场景。

### 修法

- AppShell 里 `showFilesPanel = currentPage === "chat"`：宽窗 aside、窄窗顶部入口、覆盖层抽屉三者
  同时只在智能体页渲染；其它页面不渲染任何文件入口；
- 智能体页保持原能力：表头用量、绑定、上传、文件树、拖拽调宽（宽度记忆）、预览、发送到会话；
- 窄窗（<1200）仍以顶部「共享文件」按钮打开覆盖层抽屉，行为不变。

### 边界

- 全局 `heming.asideWidth.v1` 仍保留（宽度记忆只在智能体页生效）；
- 上传/绑定失败提示、无会话提示逻辑未改。

## 2. 自动化预设

### 问题

新建成一个自动化要选动作、来源、时间、全量/导出，大多数人只需要四种固定组合；
配置成本与收益不匹配。

### 修法

- `lib/automation/presets.ts` 定义 4 条预设（纯数据 + 深拷贝函数 + 校验函数）：
  - 每日同步归档（每天 08:00，QQ+微信，增量）
  - 每 2 小时增量同步（interval 120）
  - 每天早上重扫日程（agenda，07:30）
  - 每周日导出知识库（sync，周日 20:00，archive=true）
- 自动化页顶部「常用预设」卡片，一键 `create(presetDraft)`，成功给出「已按预设创建」提示；
- 「新建自动化」表单保留为高级/自定义入口；预设建出的任务与手建完全同构，可再编辑/停用/删除。
