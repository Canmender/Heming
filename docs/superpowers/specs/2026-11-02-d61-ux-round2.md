## 2. 本轮做（三轨）

### D. 全局本机搜索（V1）
- 在命令面板新增三组本机结果（只读本机存储、**不发任何网络请求**）：
  - **任务**：标题、目标、报告的摘要命中 → 动作「打开任务」（切任务区并选中该记录）；
  - **记忆**：三层（工作/情景/语义）条目文本命中 → 「查看记忆」（切记忆区并定位/高亮该条）；
  - **插件**：名称/描述/技能名命中 → 「打开插件」（切插件区并高亮该卡）。
- 分组顺序固定：页面 → 设置 → 动作 → 任务 → 记忆 → 插件 → 成员 → 技能 → 归档；每组默认最多 5 条、超出显示「还有 N 条」；空组不出现。
- 跳转用**内存意图槽**扩展（复用 d.60 的 `paletteIntent`，新增 `open-task` / `focus-memory` / `open-plugin` 三种 kind，消费即清、幂等），消费端各加 3–5 行。
- 隐私：搜索只在本机内存/`localStorage` 里做，不发起请求、不写日志；**不搜消息正文**（E2E 正文检索需服务端索引，另立规格）。

### E. 设置页内搜索与卡片定位（V2）
- 设置页顶部加过滤框（有内容时出现结果面板）：输入关键词 → 跨分区匹配设置卡片（标题 + 关键词 + 分区名），点击结果切到对应分区并滚动到卡片、短暂高亮（2 秒淡出）。
- 建立**卡片级元数据** `lib/settings/registry.ts`（id / 标题 / 关键词 / 所属分区），设置页渲染时给每张卡加 `data-settings-id`；未来新增卡片只在 registry 加一行（并有源码守卫测试：SettingsPage 里出现的 `data-settings-id` 都能在 registry 找到）。
- 搜索为空时回到普通分区视图；Esc 关闭结果面板并清空输入。

### F. 快捷键帮助与通知中心（V3/V4）
- **快捷键帮助面板**：`?`（Shift+/，输入框内不触发）或 `Ctrl+/` 打开，按「导航 / 全局 / 编辑」分组列出全部快捷键（从现有 `lib/palette/pages.ts` 的 Alt 标注 + 静态表生成，避免两处写死）；用 `useModalA11y` 接管 Esc/焦点；设置区「关于」或导航轨「?」入口可再次打开。
- **通知中心增强**：按类型筛选（全部 / 任务 / 待确认 / 幕僚），筛选不改变未读数口径；「清空」加二次确认（应用内确认，文案写明不可恢复）；保持现有「全部已读」与点击跳转行为；筛选状态只存组件内（不持久化）。
- 验收：快捷键面板在弹窗里按 Esc 只关自己（不误关别的）；通知筛选与清空确认各有用例；空筛选结果给「该类型暂无通知」。

## 3. 明确不做
- 不做消息正文全文检索/服务端索引（另立规格）；不做设置项编辑重构；不改导航结构；不改设计 token；不引入依赖。
