## 1. 为什么拆「用户版发布说明」

工程 CHANGELOG 的读者是维护者：它写根因、文件路径、测试统计、异常码，这些对用户是噪音，
但删掉又会让维护者失去线索。因此**两份文本、两个读者、同一版本号**：

| 文件 | 读者 | 内容 | 生成物 |
|---|---|---|---|
| `CHANGELOG.md` | 维护者 | 根因 / 修法 / 验证口径 / 门禁数字 | `generated/changelog.ts` |
| `docs/RELEASE-NOTES.md` | 用户 | 一句一条「用户能感知到什么」 | `generated/releaseNotes.ts` |

- 复用 `scripts/changelog-parser.mjs` 的同一套解析（版式相同），无新增依赖；
- `build-changelog.mjs` 一次生成两份产物；
- **没有收录进 RELEASE-NOTES 的版本**：应用内只显示 CHANGELOG 标题，展开写
  「这一版还没有用户版说明；工程记录见仓库 CHANGELOG.md」——不回退到工程细节；
- 已回填最近 5 个版本；维护约定写在 `docs/RELEASE-NOTES.md` 头部（每次 bump 顺手补一条）。

界面接线：

- 设置区「关于 · 更新日志」：标题与展开内容改用用户版说明；
- 首页「最近更新」：`latestUserUpdates(3)`（有说明用说明标题，无说明回落 CHANGELOG 标题，
  **只取标题、不取 bullets/paragraphs**）。

## 2. 记忆区入口摩擦

- 「数据库」在未选智能体时「添加记忆 / 立即整理」是禁用的，原因只在按钮下方一行小字，
  而选择器在页面右上角（相隔近千像素）。现在提示条里**就地给一个选择器**，与页头同一份 state；
  选中后按钮立即可用、提示条消失。
- Tab 徽标：`个人知识库` 原来写死 `0`（WikiPanel 自管页数，本页拿不到），改为「数字不准就不显示」；
  「智能体 / 数据库」保留真实条目数。
