## 1. 本轮修了什么

### 1.1 真正坏了 / 自相矛盾的（P1）

| 问题 | 位置 | 修法 |
|---|---|---|
| 「去配置模型 / 去设置」三处都只 `setPage("settings")`，落在「个人资料」 | `HomePage`、`ChatPage`、`TaskAreaPage`、`AgentFormModal` | 统一 `openSettings("model")`；首跑引导第 1 步同源 |
| 会话头「● 已连接」= 实时通道状态，与同屏「未绑定模型」打架 | `ChatPage` 会话头 | 文案改「通道已连接 / 通道断开 / 通道连接中 / 通道已恢复」，不新增状态机 |
| 首页 Token 用量「团队」页签是「暂未开放」死文案，而团队页早有排行 | `HomePage` | 新 `HomeTeamUsage`：按白名单摘要同步 + 前 5 名 + 我的合计；关闭共享时不请求、给入口 |
| 「按日期」把本月未来日期铺成 0，且零数据无空态 | `HomePage`、`tokenUsage` 派生物 | 只列到今天；本月无记录给空态；测试改按「今天」动态构造 |
| 团队日程空态是三段术语墙、没有任何出口按钮 | `TeamPage` 团队日程 | 一句话说明 + 主按钮「去连接信息中枢」 |
| 插件安装/详情/卡片仍指向已并入 MCP Tab 的「接口区」 | `InstallDialog`、`PluginDetailDialog`、`PluginCard` | 统一「MCP 服务 Tab」「查看 MCP 服务」，测试断言同步 |
| 内置 MCP 预置可被永久删除且无恢复入口 | `lib/mcp/store.ts`、`InterfacesPage` | 新增 `removedPresetIds()` / `restorePresets()`；有删除记录时显示「恢复预置服务」并回报条数；删除确认写明可找回 |
| 设置搜索命中「软件更新」后只剩空白高亮框（无更新桥时 `UpdateCard` 返回 null） | `SettingsPage` `AboutSection` | 无桥时渲染「软件更新」说明卡，桌面安装版行为不变 |

### 1.2 模块级「半成品」补齐

- **首页底部「最新资讯」→「最近更新」**：原来的三条静态资讯写死在源码里（日期永远停在 2026-11-02），
  改成取 `generated/changelog.ts` 前 3 条真实更新，点开进设置·关于。测试同步改为断言 `CHANGELOG`。
- **团队共享语义**：勾选项改名「任务摘要 / 日程摘要 / 用量排行」、共享区加「向团队共享（只上报摘要）」标题、
  chip 加悬停说明；0 条记录时「清除共享记录」禁用。
- **记忆区导出语义**：`下载文件（桌面为导出到文件）` vs `复制 JSON`；手动条目隐藏置信度；智能体列隐藏原始 ID；
  复盘频率「每 N 轮才复盘一次」且关闭时禁用输入。

- 首页、`StaffHomeCard`、`AssistantPage` 里内联亮色（含热力图图例的 5 个 hex）改主题 token，

- 统计卡副文案去掉实现细节（「约 20 秒刷新」「含系统预设」→「此刻在线」「都在这台设备上运行」）。
- 系统智能体称呼统一「和鸣内置智能体」。
- 主题模式卡方位词纠正；「页面颜色 / 主题色 / 配色」统一叫「主题色」（旧叫法留作搜索关键词）。
- 更新日志默认最近 20 条 + 「显示更早的 N 个版本」，并注明是开发记录原文。

## 4. 维护约束（本轮新增）

- 首页「最近更新」直接读 `generated/changelog.ts`：以后写 CHANGELOG 就会自动出现在首页，
  工程细节也会跟着出现——若要做「用户版发布说明」，必须先拆出第二套生成物。
- `HomeTeamUsage` 打开页签会按团队页同一套白名单摘要同步（服务端 `(actor,date,model)` 幂等）：
  两处共用 `collectCurrentTeamUsage`，不要在首页另写一套采集，否则隐私口径会漂。
- `restorePresets()` 只在「有删除记录」时可见入口；补回的服务按预置顺序追加到列表末尾，
  若需要稳定顺序应在渲染层按 `DEFAULT_PRESET_SERVERS` 排序，而不是改存储序。
