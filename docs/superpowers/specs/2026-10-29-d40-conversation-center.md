# d.40 · 会话中心：持久列表、置顶、免打扰、一眼可见

- 日期：2026-10-29
- 相关版本：d.39.1.11.0（基线）、本 spec = d.40.1.11.0（特性位 +1）
- 上游依据：`docs/research/2026-10-28-ai-im-ux-pain-points.md`（P1 会话组织/找不到）
- 涉及包：`packages/web`（纯前端；服务端 `lastMessageAt` 已具备）
- 说明：只做本机会话组织与本地缓存预览，不上传偏好，不做全局消息全文检索。

## 0. 问题

- 会话多了只能靠雷达（按联系人）或已打开的标签找；没有「所有会话」的持久入口。
- 未读、草稿、免打扰、置顶分散在不同角落：未读在导航与首页，草稿只在输入框，免打扰藏在信息卡，置顶不存在。
- 首页只显示最近 6 条；归档页解决「收起来的历史」，但没有「现在要处理的全部」这一层。

## 1. 决策

### A. 新增「会话」页（导航第 9 项）

- `Page` 增加 `conversations`，NavRail 标签「会话」，快捷键 **Alt+9**（老页编号不动）。
- 默认导航顺序放在主页之后；已有个性化顺序的用户由 `normalizeNavOrder` 自动补在末尾。
- 页面列出**未归档**的全部会话；已归档仍只在归档页。
- 首页「最近会话」标题右侧增加「全部会话」入口，切到该页。

### B. 排序与行内容

- 排序：**置顶优先**；同组按 `lastMessageAt` 降序（缺失排最后，等值保持稳定）。
- 每行：
  - 头像 + 未读角标；
  - 标题（direct 对方名 / agent 名 / group 群名）；
  - 预览优先级：草稿 → 本机已加载最后一条 → 本机解密缓存最后一条可展示消息 → 「点击查看消息」（有 `lastMessageAt`）→「暂无消息」；
  - 行尾时间：`lastMessageAt`（缺失时回退缓存时间）；
  - 置顶/免打扰小图标。
- 预览只读本机数据：`messages` 与 `msgCache`；**不新增服务端接口、不把正文上传**。

### C. 行操作

- 点击行：打开会话（沿用 `openConversation`）。
- 「置顶 / 取消置顶」：本机偏好，排序立即变化。
- 「免打扰 / 取消免打扰」：复用 `heming.convPrefs.v1`，只抑制提醒，不影响未读。
- 「归档」：调用已有 `archiveConversation`，成功后刷新工作区；失败在页面内提示，不静默。
- 操作按钮在 hover/键盘聚焦时可见；`aria-label` 带会话名。

### D. 偏好模型扩展

- `convPrefs` 的 `ConvPref` 增加 `pinned?: boolean`；`setMuted` 与 `setPinned` 互不覆盖；
  `isPinned` / `setPinned` 导出；订阅/版本机制不变。
- 坏 JSON、未知字段、配额失败仍按「本次会话生效、不抛」处理。

## 2. 明确不做

- 不做全局消息全文检索（搜索框只按会话名过滤；消息内容检索另立规格）。
- 不做分组/文件夹、拖拽排序、服务端同步置顶/免打扰。
- 不改归档页与雷达；不引入第三方依赖。
- 不做 presence（仍需 WS 上提）。

## 3. 风险与处置

| 风险 | 处置 |
|---|---|
| 缓存预览过期或缺失 | 只展示本机已知的最后一条；缺失时如实「点击查看消息」，不猜正文 |
| 会话很多时预览遍历慢 | 只遍历未归档会话；`msgCache.list` 已有进程内视图缓存；只在列表渲染时取最后一条可展示消息 |
| 本机偏好与设备不一致 | 明确只存本机；换设备不跟随（与草稿/通知一致） |
| 置顶/免打扰互相覆盖 | 偏好写入按字段合并，关闭一个只删该字段 |
| 导航新增第 9 项影响老快捷键 | 老页 digit 不动，新页固定 9；个性化顺序缺项自动补末尾 |

  归档后从列表消失并出现在归档页；免打扰后不提醒但未读仍增长。
