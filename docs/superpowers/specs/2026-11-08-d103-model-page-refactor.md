# d.103 模型页重构：原生、无品牌、少操作

- 日期：2026-11-08
- 版本：`d.103.2.42.0`（特性 +1）
- 承接 d.100–d.102 的模型页。

## 1. 四条反馈与本轮改法

| 反馈 | 改法 |
|---|---|
| 设置页面不要出现模型 | 设置区去掉「模型」页签与网关卡片；模型相关操作只在导航「模型」页。设置区原页签保留本机设置（上下文预算 / 工具确认 / 文件编辑 / 存储水位 / 密钥存储），改名为「高级」 |
| 内置就不要出现第三方名字，不要开关服务 | 页面不再出现第三方产品名、网关地址、版本、端口，也没有启动/停止/重连按钮；模型能力随应用启动，用户只需要「加来源 / 选模型」 |
| 操作极为繁琐 | 主路径收敛成两件事：加来源、看模型；其余（路由分组、用量、备份、同步、库、命令）收进「更多」折叠区 |
| UI 优化 | 五个一级分区、卡片式来源选择、统计卡片、统一圆角与间距；来源列表只留「测试 / 删除」两个动作 |

## 2. 新结构（模型页）

- **模型**：可用模型统计 + 模型卡片（可搜索）；空状态一键跳到「添加来源」；
- **添加来源**：
  - 订阅卡片（Claude / ChatGPT / Copilot / Gemini / Antigravity）：点一下打开登录窗口，完成后自动出现；
  - API Key 服务商卡片（DeepSeek / OpenAI / Anthropic / Kimi / 智谱 / MiniMax / 通义 / Mistral / Groq / xAI）：点卡片只需粘贴一个 Key；
  - 自定义地址（名称 / 地址 / Key / 模型列表，均可留空自动读）；
  - 已添加来源：紧凑列表，只保留测试与删除；
  - 保存成功后自动刷新模型目录并回到「模型」；
- **账号**：已登录账号与额度、再登录入口；
- **路由**：实时链路（d.101/102）+ 候选链入口，路由分组收进折叠区；
- **更多**：用量、备份与恢复、多机同步、资源库与搜索、高级命令，全部折叠。

## 3. 去除的内容

- 设置区「模型」页签与网关卡片（`MagpieGatewayCard` 删除）；
- 模型页的网关地址/版本/端口/状态与启动、重启、停止按钮；
- 用户界面中的第三方产品名（保留文档与源码注释里的 MIT 归属说明）；
- 首屏一次性铺开的表单（供应商原始输出、分组/用量/备份全部展开）→ 折叠或卡片化。

## 4. 关联调整

- 「管理模型」「去设置」等入口统一跳到导航「模型」页（不再进设置区）；
- 模型路由页的「可用模型」提示改为「来自模型目录」；边界说明去掉第三方产品名；
- 命令面板里模型路由页的描述去掉「语义移植」字样。

## 5. 验证

- `ModelPage` 用例重写：五分区、无启停/无第三方名、搜索、服务商卡片加 Key 后自动刷新并回模型页、订阅走登录窗口、来源删除、账号表、更多里的高级命令；
- 设置区用例更新：不再有网关字段，上下文预算等本机卡仍在；设置搜索结果卡数量 14；
- 任务区/首页/路由页跳转断言更新为「模型页」；
- web 全量门禁与 typecheck 见发版记录。
