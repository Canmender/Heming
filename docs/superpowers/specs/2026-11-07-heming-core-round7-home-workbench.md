- 分支：`feat/d77-heming-core`
- 触发：用户给出本体功能优先级 **主页 > 智能体应用 > 团队 > 插件区 > 记忆区 > 设置区**，本轮先做主页
- 方法：主页专项只读审计（真实浏览器 1600×1000 / 1100×800 + 造数据 + 断网模拟）→ 按「若只做 3 件事」实施

## 1. 审计结论（摘要）

主页当时是「项目仪表盘」：统计成员数、Token、更新日志；用户每天打开它要的三件事一个都没有——
**有什么要我处理、上次干到哪、手上有什么在跑**。实测（造数据，不是推测）：

- 造一条「进行中」任务：智能体页任务页签显示「进行中 1 / 整理本周周报」，首页 0 痕迹；
- 造一条「待确认」approval 通知：导航红点 + 通知中心可见，首页 0 提及；
- 四张统计卡 / 智能体动态 / 系统状态：0 个可点元素；
- 断网阻断 `/api/team`：团队卡片报错，但统计卡静默显示 0，与真实 0 无法区分；「实时通道」是写死文案；
- 密度：1600 一屏塞 11 块、约一半是空态/低价值；1100 需在 main 内滚 515px，第二屏全是低价值块。

## 2. 本轮实现（审计「若只做 3 件事」）

### 2.1 首屏动作区

- `components/home/NeedsAttention.tsx`：只列**可动作**条目——HITL 待确认 / 运行中任务 / 未读通知
  （approval 通知由 HITL 覆盖，不重复列）；每行一个跳转：审批/任务 → 对应会话或任务区并选中，
  幕僚/自动化 → 对应页；**无事整块不渲染**。
- `components/home/RecentConversations.tsx`：按 `lastMessageAt` 倒序取 3 个会话，头像/名称/相对时间/未读角标，
  点击 `openConversation`（配合 d.83 直接回到上次阅读位置）；空态给「去智能体页」。
  替代原「智能体动态」（不可点、与智能体页重复）。

### 2.2 统计卡变动作指标

| 旧 | 新 | 点击 |
|---|---|---|
| 团队成员 | 待处理（HITL 1 + 未读非审批通知） | 有则直达（审批会话 / 第一条未读目标） |
| 在线成员 | 运行中任务 | 第一条运行中任务或任务区 |
| 我的智能体 | 我的智能体 | 智能体页 |
| 今日动向 | 今日动向 | 团队页；`teamError` 时显示「—」不可点 |

`StatCard` 支持 `onOpen/actionLabel`，按钮化并带焦点环。

### 2.3 首屏减负与数据诚实

- 删右栏「在线成员」卡（与统计卡重复）、「最近更新」三卡墙（收敛为页脚入口）、「系统状态」整卡
  （收敛为页脚一行「服务 / 文件目录」）；「实时通道 会话内连接」写死文案随之消失。
- Token 卡本月无记录 → 折叠成一行（含「去配置模型」入口），有记录才展开 tab 与热力图。
- 团队动向：`items-start` 不再被右栏拉伸；显示「HH:MM 更新 / 刷新」——首页不轮询，但要让用户知道
  数据多旧、并能手动刷新。
- 页头：版本号与「今日已用」徽标 → 「新对话 / 派任务」两个动作（版本仍在设置·关于，更新日志有入口）。

## 3. 明确没做

| 未做 | 原因 |
