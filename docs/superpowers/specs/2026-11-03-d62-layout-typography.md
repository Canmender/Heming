# d.62 · 页面布局与 UI 排版统一（规格）

- 日期：2026-11-03
- 状态：**本轮实施**
- 触发：用户「优化页面布局和 UI 排版」
- 审计依据：16 个页面组件的源码扫描 + `.tmp/ux/before` / `.tmp/ux/after` 两批流程截图
- 红线不变：本地驱动、E2E 不降级、个人数据不出设备、HITL 不做全放行。

## 1. 审计数据（改造前）

| 维度 | 现状 | 问题 |
|---|---|---|
| 字号 | 11 档：`9px×17 / 10px×195 / 11px×376 / 12px×454 / 13px×50 / 14px×13 / 15px×10 / 16px×1 / 17px×8 / 18px×3 / 20px×1` | 档位太密、随手取号；页面标题 15/16/17px 混用（`AutomationPage` 15/600、`InterfacesPage` 17/800、`HomePage` 17/800） |
| 页面内边距 | `p-6`（24）/ `px-8`（32，聊天）/ `px-6 py-6`（任务区）混用 | 切页时内容左右边缘跳动 8px |
| 内容宽度 | 通栏（首页/插件/接口）、`max-w-[520px]`（设置列）、`max-w-[860~900px]`（自动化/幕僚列表） | 宽屏上各页内容宽度来回变 |
| 页头结构 | 有的页有 `<h1>+副标题+操作`，有的页只有 `<h1>`，有的页（团队/设置）把标题埋在分栏里 | 标题层级与位置不一致 |
| 滚动容器 | 有的在页面根（`h-full overflow-y-auto`），有的在内部列表 | 「整页滚」与「列表滚」混用，页头会跟着滚走 |
| 聊天区 | 消息栏 `px-8`、无最大宽度（1440 宽屏下正文行宽近 980px） | 中文长行难读；输入区与消息区边距不一致 |

## 2. 设计决策（本轮落地）

### 2.1 排版档位（`index.css` 的 `ui-*` 类）
| 类 | 规格 | 用途 |
|---|---|---|
| `.ui-page-title` | 18/24 · 600 · -0.01em | 页面级标题（全站唯一档） |
| `.ui-page-sub` | 12/20 · muted | 标题下一句话说明 |
| `.ui-section-title` | 13/20 · 600 | 卡片/分区标题 |
| `.ui-body` | 13/22 | 正文 |
| `.ui-body-sm` | 12/20 | 次要正文/表格 |
| `.ui-caption` | 11/16 · muted | 注释/时间/辅助 |
| `.ui-micro` | 10/14 · 500 · muted | 角标/徽标（仅此用途） |
| `.ui-numeric` | tabular-nums | 数字对齐 |

规则：**页面标题、副标题、section 标题必须用上表类**；正文/注释在改动到的区块里就近迁移；`text-[9px]` 不再新增（已有 17 处随本轮触及的区块改为 `ui-micro`）。

### 2.2 布局基元 `components/layout/PageShell.tsx`
- 页头固定：`px-6 pt-5 pb-4` + 底部 `border-line-soft`；标题 `ui-page-title`、副标题 `ui-page-sub`、右侧 `actions` 槽、可选 `headerExtra`（页签/筛选条）。
- 内容区：`px-6 py-5` 可滚动；宽度档位 `full | wide(1200) | readable(960) | narrow(720)`。
- 双栏/三栏页面（团队/设置/智能体/聊天/任务）用 `scroll={false}` 保留自己的滚动，但**必须复用同一个页头**（去掉页面内各自的 `<h1>` 块）。
- 全站统一内容内边距 **24px**；分区间距 **16px**（卡片栅格）；页头到内容 **20px**。

### 2.3 页面归属与宽度
| 页面 | 宽度档 | 说明 |
|---|---|---|
| 主页 | wide 1200 | 统计卡 + 团队动向 + 资讯三栏 |
| 插件区 / 接口区 / 技能区 / Registry | wide 1200 | 卡片栅格 |
| 自动化 / 幕僚 / 归档 / 工作区 | readable 960 | 列表为主 |
| 记忆区 | readable 960 | 卡片列表 |
| 设置区 | narrow 720（内容列） | 页头通栏 + 内容列 520→720 上限，避免超长行 |
| 团队 / 团队看板 | full（分栏） | 页头固定，分栏自滚 |
| 智能体 / 聊天 / 任务区 | full（分栏） | 聊天消息列 `max-w-[880px] mx-auto` |
| 信息中枢 | full（分栏） | 页头固定 |

### 2.4 聊天页排版
- 消息区：滚动容器保持，但内容列 `mx-auto w-full max-w-[880px]`，长行不超过约 80 个汉字；
- 输入区与消息列同宽（`max-w-[880px] mx-auto`），工具栏/快捷键提示对齐；
- 空白态与示例提示继承同一宽度。

## 3. 本轮做（三轨，文件级不重叠）

- **A（list 页）**：`PluginsPage` / `InterfacesPage` / `AutomationPage` / `StaffPage` / `SkillsPage` / `RegistryPage` / `InfohubPage` 迁到 `PageShell`（宽 wide/readable 按上表），删除各页自写 `<h1>` 块，section 标题统一 `ui-section-title`，卡片间距统一 `gap-4`。
- **B（分栏页）**：`TeamPage` / `TeamBoardPage` / `SettingsPage` / `MemoryPage` 用 `PageShell scroll={false}` 包页头，内部标题/标签栏字号统一，内容左右内边距统一 24px；设置内容列上限 720。
- **C（聊天与壳）**：`AssistantPage` / `ChatPage` / `TaskAreaPage` 页头统一（列表列头、会话标题、任务区标题）；聊天消息列与输入区同宽 880 居中；`App.tsx` 右侧栏表头用 `ui-section-title`、与左侧导航内边距对齐；空态/示例/骨架沿用同宽度。

不动：登录页视觉、导航轨图标与顺序、主题色与 token 取值、全部交互行为与文案语义。允许改：class 与包裹层级（必要时新增 `div`）。

- 三轨定向用例全绿（页面渲染/角色可达名不回归）、`tsc --noEmit`、`pnpm -r build`；
- 发布前全量门禁（逐包、允许单包重试一次）；
- 视觉：`node .tmp/ux-capture.mjs` 重截 13 页，与 `.tmp/ux/after`（d.60 基线）对照——要求「左边缘对齐、标题层级一致、宽屏内容不再左右跳」；
- 版本：`d.61.2.22.0`（纯排版/布局，计入修订位）。
