# 团队第二轮：从「定位到人」到「定位到那条动向」（d.91.2.42.0）

- 日期：2026-11-07
- 分支：`feat/d77-heming-core`
- 来源：团队专项审计（`.tmp/d82/audit-team/report.md`）P2 剩余项——
  「首页条目只定位到人、不到条目（itemHighlighted=false）」「看板空态巨型空卡」「隐私说明一页 4 次」
- 说明：本轮与并行会话的「插件独立分发 / 在线目录」改动同处一个工作区；本批只动团队相关文件

## 1. 动向深链：成员 + 那一条

上一轮（d.89）把首页动向点击从「只跳团队页」改成 `focusTeamMember(actorId)`——落到人，但用户点的是
「鲍勃发版到生产」这件事。本轮补完：

- ui store 新增一次性投递槽 `teamFocusActivityId` + `focusTeamActivity(activityId, actorId)`：
  进团队页 + 选中成员 + 记住要定位的动向 id；`consumeTeamActivityFocus()` 读走即清。
- TeamPage 消费：切回「动向」视图 → 等该条出现在可见列表（effect 依赖 `visibleActivities` 重跑）→
  `scrollIntoView({block:"center"})` → 加高亮（subtle 底 + 强描边）2.4 秒后自动褪去。
- 只滚已渲染的列表：若该条被当前筛选（任务/日程/全部）过滤掉，不强行改筛选，等用户在既有筛选下看到；
  意图随后清空，不会把页面长期钉住。
- 首页按钮改为 `focusTeamActivity(a.id, a.actorId)`。

## 2. 看板空态压缩

看板两列原来固定 `min-h-[160px] + py-6`，空态时是两块「巨型空卡」。改为：有内容才保留最小高度，
空态时高度随内容收缩（仍保留两列语义与标题），减少空页面上的视觉噪音。

## 3. 隐私口径收敛

团队页原来在 4 处重复「只含摘要 / 不含对话」：共享条、动向空态、看板头、日程段。
收敛为：共享条承担完整口径（含「关闭只停止上报」），各视图只在**该视图自己的边界不同**时补充
（日程段说明「标题 + 到期档位」、用量段说明「token/模型/连接名」）；动向空态与看板头去重。

## 4. 测试

- `store/ui.test.ts` +1：`focusTeamActivity` 一次性投递（成员 + id + 进团队页），消费只清 id 不清成员。
- `TeamPage.test.tsx` +1：预置 intent 后渲染 → 该行存在、`ring-1` 高亮、`scrollIntoView` 被调用、
  intent 已消费（不会切走回来还被钉住）。
- `HomePage.test.tsx`：条目点击断言补 `teamFocusActivityId`。
- 真机（1600×1000，0 error）：用 `Page.addScriptToEvaluateOnNewDocument` 拦截 `/api/team*` 造
  2 成员 + 2 条动向（不动服务端数据）→ 首页点「发版到生产」→ 团队页选中鲍勃、目标行高亮、
  成员详情显示「近 7 天动向 1 条 · 用量未共享」。
- d39 生命周期压测（100 次切页）按新不变量更新：首页持有**一条**在场连接（不随切页增减），
  聊天连接仍严格「进助手页建、离开关」；100 次切换后只剩那一条在场连接、`chatSocketCount=0`。
  同时把在场连接改为依赖 `token` 而不是 `status`——启动会话恢复会短暂经过 pending，
  依赖 status 会让连接「连上→断开→再连上」。
