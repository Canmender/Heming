# 和鸣 · 用户版发布说明

> 这份文件**面向用户**：只写「用户能感知到什么」，一句一条，不写实现细节、文件名、测试数量或缺陷根因。
> 工程记录（根因/修法/门禁数字）一律留在 [CHANGELOG.md](../CHANGELOG.md)，两边不要互相复制。
> 版本号与 CHANGELOG 对齐；没有写在这里的版本，应用内只显示一行标题，不展示工程细节。
> 维护方式：每次 bump 后，在 CHANGELOG 之外**顺手补一条**（一两条即可）；`node scripts/build-changelog.mjs` 会一并生成。

## d.103.2.42.0（2026-11-08）— 「模型」页更简单了

- 设置里不再有「模型」页签：所有模型相关的操作都在导航「模型」页。
- 加模型只需一步：点订阅卡片去登录，或点服务商卡片粘贴一个 Key；不用再填地址、端口或开关服务。
- 模型页现在只有五个分区：模型、添加来源、账号、路由、更多；用量、备份、同步等都收在「更多」里。
- 页面上不再出现第三方产品的名字——对用户来说这就是和鸣自己的模型能力。

## d.102.2.42.0（2026-11-08）— 「实时链路」更好用了

- 顶部直接看到总数、进行中、成功、失败与平均耗时；可以按状态筛。
- 点一下左边的智能体或右边的账号，只看经过它的请求；节点上标着请求数。
- 系统开了「减少动态效果」时，不再播放移动圆点。
- 页面会标出「最后读取」时间，暂停后也知道数据新旧。

## d.101.2.42.0（2026-11-08）— 「模型」页能看见请求怎么走了

- 新增「实时链路」：左边是发请求的智能体，中间是和鸣内核，右边是最终用到的账号/Key；
- 连线会动：蓝色是正在进行，绿色成功，琥珀色表示失败后换人；点一条线能看到每次尝试的耗时与状态。
- 下方有请求列表，和上面的图联动；没请求时会告诉你怎么试出来。

## d.100.2.42.0（2026-11-08）— 导航栏多了「模型」页

- 供应商、订阅账号、分组路由、模型、用量、备份与同步、库与搜索，集中在一个页面里，不用再去命令行。
- 登录订阅账号会打开一个终端窗口完成浏览器登录；备份口令也在终端里输入，不经过页面。
- 浏览器版只能看不能改（管理命令需要桌面端）；高级参数仍可在页面的「终端」分区直接跑。

## d.99.2.42.0（2026-11-08）— 更新下载时能看到进度条了

- 设置·关于里点「下载更新」时，会显示进度条和「已下载 42%（105 MB / 250 MB · 2.0 MB/s）」。
- 下载完成后进度条消失，按钮变成「重启并安装」。

## d.98.2.42.0（2026-11-08）— 桌宠改成插件了：在插件区下载安装，不再跟着主程序

- 桌宠从主程序里拆出去了：主程序不再带桌宠、不再带 5MB 模型，安装包更小。
- 装桌宠：插件区 → 桌面小组件 → 安装（从云端选「桌宠」，或导入本地插件文件）；装好到设置·外观里打开「在桌面显示」。
- 卸载也在这里：会删掉插件文件与模型，卸载前会请你确认。
- 用起来和以前一样：点它说话、双击开心、拖动记住位置、右键菜单、托盘、鼠标穿透、有消息冒气泡。
- 老用户升级后桌宠会先消失（因为它现在是插件），插件区会提示去装；装上后位置、缩放、绑定与打扰强度自动带过来。

## d.96.2.42.0（2026-11-07）— 插件区有了「下载安装」和云端插件库

- 插件页右上多了「下载安装」：打开云端插件库列表，看到能装的插件，选一个就能装。
- 插件区也多了「仓库」标签页，可以按名称/描述搜插件，能看到版本、已装/可更新、权限与贡献。
- 安装前仍会展示权限和内容指纹；下载的清单会校验，不对就不装。
- 自己写清单的人继续用「手动安装」（粘贴 JSON / 选文件）。

## d.95.2.42.0（2026-11-07）— 你自己开着的 magpie，和鸣直接接入

- 如果本机已经有 magpie 在跑，和鸣会直接连它，不会另起一个、也不会抢端口；设置里显示「已接入本机 magpie」。
- 点「断开」只是和鸣不再用它，不会关掉你开着的 magpie。
- 和鸣自己启动的那份仍然是「启动 / 重启 / 停止」，两种状态在设置里分得清。

## d.94.2.42.0（2026-11-07）— 模型相关只剩「magpie 目录 + 模型」

- 候选链的选路档从 8 档减到 7 档：不再有「参考价优先」，因为价格由 magpie 管，和鸣不复制一份价目表。
- 本月逐候选用量仍按 token 展示，不再估金额（网关不给价格，估出来只会是假账）。
- 与模型连接相关的旧协议实现已清理（内部改动，用户无感）；模型仍全部来自本机 magpie。

## d.93.2.42.0（2026-11-07）— 团队页有了「工作台」：自己建团队、写目标、排方案、派任务

- 团队页最前面多了「工作台」：左侧是你的团队列表，可以新建团队、起名字、写团队目标。
- 每个团队里能把目标拆成「方案」，再往下派「任务」：指定负责人、归属方案、截止时间。
- 任务可以上传交付物（走共享文件库），点状态就能从「待开始 → 进行中 → 已完成」流转。
- 智能体也能帮你维护：可以列出团队、读目标方案、建团队、派任务、改状态——写操作会先请你确认。

## d.92.2.42.0（2026-11-07）— 模型网关随和鸣一起装好

- 和鸣安装包自带 magpie：装完打开就能用，不用再自己启动一个网关。
- 设置·模型会显示「内置 magpie 运行中（版本）」，也可以在这里启动/重启/停止；地址由和鸣自动接好。
- 想连别的机器上共享的 magpie，仍可以在「高级：手动指定网关」里填地址与网关 Key。
- 模型账号、订阅与多账号轮换都在 magpie 里管理，和鸣这边不保存任何供应商 Key。

## d.91.2.42.0（2026-11-07）— 团队动点点进去就是那件事

- 首页团队动向点进去，会选中那位成员并高亮你点的那一条动向。
- 团队看板在没有内容时不再出现两块很高的空卡。
- 团队的隐私说明不再一页重复四遍。

## d.90.2.42.0（2026-11-07）— 模型统一走本机 magpie

- 设置·模型不再让你逐个填服务商、地址和 Key：改成填一条本机 magpie 网关（默认 127.0.0.1:3425），点「读取模型」就能看到你现在能用的所有模型。
- 你已经在用的 Claude Code / Codex / 各家 API Key，都交给 magpie 管；它的多账号轮换与额度选路对和鸣透明，和鸣这边只填网关 Key。
- 智能体绑定和候选链现在绑的是「模型」：换模型不用改 Key，候选链就是多个模型之间自动切换。
- 旧版保存的供应商连接（含 Key）已按决定清除；系统提示词与历史用量保留。没有 magpie 时会在设置页如实提示。

## d.89.2.42.0（2026-11-07）— 团队页更诚实

- 人在应用里就算在线了：以前不进某个对话，团队里会把你显示成离线。
- 关掉共享时说明白：只停止以后上报，已经传上去的摘要还在，要撤回请用「清除共享记录」。
- 成员详情多了「近 7 天动向几条」和用量；没有数据时会如实说。
- 首页团队动向点进去，会落到这条动向的成员。
- 团队只有你时，页面会说明新同事账号从哪来。

## d.88.2.42.0（2026-11-07）— 插件从云端装，magpie 网关变成可选插件

- 安装插件多了「从云端浏览」：能看到有哪些独立插件包、版本与权限，点一下就能装；下载后会校验内容指纹，和目标不一致就不装。
- magpie 网关改成独立插件：装了它，设置·模型里多一个「magpie 本地网关」，点一下就把地址和模型填好（Key 仍自己填）；不装、或用不到的人，软件里不会多出这条配置。
- 本机消息采集也走同一个云端插件入口；两个插件都**不随安装包分发**，用的时候自己去插件区装。
- 插件停用后它带来的模型预设会一起消失；已经保存的模型连接不受影响。

## d.87.2.42.0（2026-11-07）— 名册更好找，提示不啰嗦

- 智能体多了以后，左栏可以直接搜索；系统与自建分开成组。
- 「编辑」入口一直看得见，不用先猜哪里能点。
- 任务详情里「还没绑定模型」不再同一屏说两遍。
- 复制报告失败时会说明原因和替代做法，不再点了没反应。

## d.86.2.42.0（2026-11-07）— 任务区更稳、运行中可以停

- 在任务区选中一次运行后切到「对话」再切回来，仍停在原来那条记录上；刷新也一样。
- 运行中的任务在右侧汇总卡可以直接「停止运行」。
- 窄一点的窗口里，「开始运行」按钮也会留在看得见的位置。
- 对话右上角三个图标按钮补上了悬停说明。

## d.85.2.42.0（2026-11-07）— 模型路由页 + 本机消息采集插件

- 插件区「模块」里多了「模型路由」：把几条模型连接串成一条链，第一个答不了自动换下一个；选路可选「按价格 / 按用量 / 按速度 / 按权重 / 轮流」等，冷却与本月各候选用量都能看见。
- 候选链的管理从设置区搬到了「模型路由」页，设置区只留一个入口。
- 插件区多了一个可安装的示例插件「InfoHub 采集桥」：启动本机采集桥、装上插件、连接一次，就能让智能体查看本机 QQ / 微信归档的采集状态、检索记录、看日程；真正采集前仍要你确认。
- 停用「模型路由」模块后，选路回到你自己排的顺序，对话与失败切换照常工作。

## d.84.2.42.0（2026-11-07）— 主页变成工作台

- 打开主页第一眼能看到「需要你处理」：等你确认的操作、正在跑的任务、还没看的通知，点一下就到。
- 「最近对话」直接接着上次聊，不用先进智能体页再找。
- 四张统计卡现在能点：待处理 / 运行中任务 / 我的智能体 / 今日动向。
- 主页更短了：在线成员、系统状态、更新日志等收敛成一行或一个入口；没有用量时 Token 卡折成一行。
- 页头多了「新对话」「派任务」两个入口。

## d.83.2.42.0（2026-11-07）— 刷新/切回会话，回到上次读到的位置

- 在长对话里往上翻着看，按 F5 或切到别的会话再回来，仍停在那一屏。
- 本来就在看最新消息的话，回来还是跟着最新消息走。

## d.82.2.42.0（2026-11-07）— 第一次配模型少绕两圈

- 已经配过连接、只是某个智能体没绑定时，对话页提示条里可以直接选一个用，不用再跳去设置。
- 设置·模型点「常用服务商」预设后，只剩 API Key 要填，光标已经停在那里。

## d.81.2.42.0（2026-11-07）— 更新日志改说人话；记忆区少跑一趟

- 设置区「更新日志」现在只讲这一版对用户的影响；想看实现细节的，去仓库 CHANGELOG.md。
- 记忆区「数据库」没选智能体时，按钮旁边就能直接选，不用再去右上角找。
- 「个人知识库」页签不再显示写死的 0。

## d.80.2.42.0（2026-11-07）— 刷新后连所在 Tab 也留在原地

- 团队、智能体、插件区、记忆区的页内 Tab，刷新后不再回到默认页签。
- 插件区「模块」页的说明改用日常说法（「本机数据 N 项」「状态：已生效」「后台任务」）。

## d.79.2.42.0（2026-11-07）— 刷新不再被弹回主页

- 在智能体页聊到一半按 F5，回来仍在那个对话；团队、插件、设置页也一样。
- 关掉应用再打开仍回主页（刷新是「同一会话」，重启是「新一次使用」）。
- 插件区的工具说明不再显示原样的 Markdown 符号；「全部恢复启用」点了会有明确反馈。

## d.78.2.42.0（2026-11-07）— 称呼统一

- 首页与编辑器里的系统智能体统一叫「和鸣内置智能体」。

## d.78.2.41.0（2026-11-07）— 六页体验修缮

- 「去配置模型 / 去设置」都会直接打开设置里的「模型」，不再停在个人资料。
- 对话顶部的「已连接」改为「通道已连接」，不会再和「还没有绑定模型」打架。
- 首页的「团队」用量可以看全站排行前 5 名与自己的合计。
- 首页「按日期」只列到今天，不再出现未来的 0；底部资讯换成真实的最近更新。
- 团队日程没有数据时，可以直接从空态去连接信息中枢。
- 插件区的旧名字「接口区」全部改成「MCP 服务」；误删的内置服务可以一键找回。
- 网页版设置里的「软件更新」不再是一块空白；更新日志默认只列最近 20 个版本。
- 记忆区两个「导出」分清了「下载文件」和「复制 JSON」；手动记的条目不再显示置信度。
- 外观设置里的「页面颜色 / 主题色 / 配色」统一叫「主题色」。

## d.77.2.41.0（2026-11-07）— 插件更好找、更好装

- 插件区可以按名称、技能、服务搜索，并按「已启用 / 已停用」筛选。
- 安装完成后自动回到插件列表并高亮新插件；插件详情会说明哪些能力它没有声明。
- 插件声明的权限上限真正生效：声明只读的插件拿不到写工具。
