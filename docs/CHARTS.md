# 图表能力

和鸣的内置数据可视化能力。蒸馏自 [Lieflat Charts](https://github.com/larashero3-dotcom/lieflat-charts)
（PolyForm Noncommercial License 1.0.0），并按和鸣的架构重写了渲染层。

## 怎么用

直接跟智能体说「把这组数据画一下」就行。智能体会：

1. 调 `chart_types` 查候选图型（按数据形状匹配）；
2. 调 `chart_render` 渲染，拿到一段 ` ```chart ` 围栏块；
3. 把围栏块原样贴进回复——你在聊天气泡里直接看到图。

图下方有两个动作：**导出 HTML**（单文件、可离线、可用系统程序打开）与**打开**。

## 两个通道的分工

| | 回答什么 | 在哪 |
|---|---|---|
| `chart_types` 工具 | **有哪些图型** | 运行时按需调用，返回完整候选清单 |
| 内置技能「数据可视化」 | **怎么画好** | 每轮注入（选型顺序、标题写法、数值诚实性） |

上游 SKILL.md 有 40KB，而和鸣单轮技能注入预算只有 1600 字符——
整段塞不进去。所以只取骨架，**图型清单交给工具**（要多少给多少），
技能只留方法论。两边不重复。

## 视觉语法（不可让步的三条）

1. **明度即数据**——最重要的系列最深/最黑，多系列按重要性分配，不按顺序随便拿。
2. **柱状图不断轴**——柱的契约是长度∝数值，断轴毁契约。极端值就让它冲天。
3. **数值与视觉严格成正比**——面积编码用 sqrt 换算半径，不拿数值直接当半径。

配色四套：mono（黑白灰，默认）/ porcelain（青瓷蓝）/ palm（椰林绿）/ wire（编辑部红）。
**同一份图只锁一套色彩系统**。类目数超过彩色预设容量时自动回落到 mono 灰阶。

## 规范怎么传

图表规范以 ` ```chart ` 围栏块随消息正文走，**不是**消息 payload 的新字段。

围栏块是普通文本 → E2E 加密、跨端同步、消息撤回全都天然覆盖。
不需要给协议加字段，也就不会漏掉某条链路。

```chart
{"type":"F1","title":"哪个季度增长最快","points":[{"label":"Q1","value":82},{"label":"Q2","value":128}]}
```

渲染消息时正文会剥掉围栏，图表单独渲染成卡片（含图的气泡放宽到 86%）。

## 文件

```
packages/web/src/lib/charts/
├── tokens.ts      Mono token（色板/字体/形状/动画/确定性伪随机）
├── palette.ts     四套配色预设 + 暗卡反转 + 容量回落
├── catalog.ts     图型目录（按数据形状索引）+ 别名映射
├── spec.ts        zod schema + 围栏块解析
├── renderer.ts    纯 SVG 渲染器（19 个图型分支）
├── exportHtml.ts  自包含单文件 HTML（离线可用，无 CDN 依赖）
├── tools.ts       chart_types / chart_render
└── client.ts      桌面端走 IPC，浏览器端降级为下载

packages/desktop/chart-fs.js   图表导出桥（写 ~/Heming/charts）
```

## 导出到磁盘

- **桌面端**：写到 `~/Heming/charts/<标题>-<图型>.html`，可用系统程序打开。
  文件名走**白名单清洗**（不是过滤危险字符——过滤法漏一个 Windows 保留名就是漏洞），
  路径穿越有双重防护，目录固定不可配置。
- **浏览器端**：没有本机文件系统，降级为浏览器下载，界面上明确告知文件去向。

## 已知限制

- **Anthropic provider 不支持工具调用**（既有设计），所以绑 Anthropic 的智能体用不了
  `chart_*` 工具——和 `self_*` 一样。
- 未实现的图型会退到替代图型，不是上游那个图型的复刻。
- 地图（GeoJSON）未实现。
