# 示例 03 · 五种命令 target（v5 声明式）

**教会你**：命令面板里的「快捷入口」怎么加；五种 target 各自能做什么、限制在哪。

```bash
node scripts/plugin-lint.mjs plugin-kit/examples/03-commands
```

## target 速查

| kind | 字段 | 行为 | 什么时候用 |
|---|---|---|---|
| `page` | `page` | 跳到某个页面 | 「去插件区 / 去知识库」这类导航 |
| `skill` | `name` | 跳到技能区并定位到该技能 | 你有明确的技能入口 |
| `settings` | `card` | 跳到设置区并定位某张卡 | 引导用户改某个设置（如主题） |
| `unit` | `unitId` | 打开插件区某能力单元详情 | 指向模块/内置能力 |
| `plugin` | — | 打开本插件详情 | 「关于本插件」「看权限」 |

## 限制

- `skill` 的 `name` **必须是本插件 skills 里的名字**，否则解析失败（这是本示例里保留一条技能的原因）。
- `page` / `settings.card` / `unit.unitId` 在清单层只做形状校验；宿主跳转时按自己的目录解析，找不到就停在原页（不会白屏）。
- 命令只出现在命令面板的「插件命令」分组；插件停用/卸载后立即消失。
- 上限：每个插件最多 30 条命令；`id` 插件内唯一。

## 抄的时候注意

- 命令是**入口**，不是逻辑：它不会「执行」任何东西，只是把用户带到该去的地方。
- 别用命令做「一步完成业务流程」的暗示；真正的流程写在技能 `instructions` 里。
