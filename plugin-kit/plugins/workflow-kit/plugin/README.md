# 工作流引擎 · 和鸣插件包

这个目录是给**和鸣插件区**安装的声明式插件包（`plugin.json`，schemaVersion 5）。
它只声明三件事，不携带代码、不携带密钥：

1. **一个本机 MCP 服务**：`http://127.0.0.1:8777/mcp`（由你手动启动的独立服务提供）；
2. **三个技能**：工作流设计 / 运行工作流 / 从 n8n 迁移工作流；
3. **一条命令**：打开本插件详情。

## 安装前

先在本仓库启动服务（需要 Node.js ≥ 24）：

```bash
pnpm install
pnpm build
node dist/server/main.js
# 看到「工作流引擎（独立插件）已启动」即可
```

- 编辑器：<http://127.0.0.1:8777/>
- MCP 地址：`http://127.0.0.1:8777/mcp`

## 在和鸣里安装

1. 和鸣 → 插件区 →「手动粘贴清单」→ 选择 `plugin/plugin.json`；
2. 安装预览里会显示「网络访问：127.0.0.1:8777」与 3 个技能、1 个命令；
3. 安装后到**接口区**找到「工作流引擎」→ 连接（首次会列出工具，默认全部关闭）；
4. 按需打开工具（`workflow_run` 等写操作会走人工确认）；
5. 智能体即可通过技能使用；你也可以随时打开编辑器手动搭流程。

## 数据与安全

- 服务只监听 `127.0.0.1`，数据在自己的 `data/` 目录，不读写和鸣的任何数据；
- 插件本身不执行随包代码、不含密钥；MCP 连接由接口区管理；
- 不需要时：停掉服务、在和鸣里停用/卸载插件即可，互不影响。
