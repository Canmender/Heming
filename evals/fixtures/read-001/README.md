# 和鸣（Heming）项目速览

和鸣是一个本地优先的桌面智能体工作台：模型调用、工具执行与会话记录都在本机完成，
数据默认不出机器。它把「文件编辑、MCP、记忆、技能」放进同一条可审计的运行时里，
方便长期做能力调优与回归。

## 三条要点

1. **本地优先**：会话记录、文件改动与 token 用量都留在本机，云端同步是可选项。
2. **工具可审计**：每次工具调用与结果都会写入 rollout，失败原因按类型归档，方便复盘。
3. **技能即插件**：能力以技能包的形式安装与卸载，不用改主程序就能扩展工作流。

## 快速开始

- 安装桌面端后，在「设置 → 文件编辑」里添加一个可写根目录；
- 打开任意会话，输入 `@` 选择智能体；
- 用 `/` 唤起命令面板，`Ctrl+K` 打开快捷切换；
- 想复现一次评测，运行 `pnpm eval:agent`（确定性假网关，不联网）。
