# magpie 网关（和鸣插件）

把本机 [magpie](https://github.com/yetone/magpie) 网关接成和鸣的模型来源。
**magpie 是独立软件，不随和鸣分发**：和鸣只提供一个「连接怎么填」的预设，不读、不存 magpie 的账号与 Key。

## 它贡献什么

| 能力 | 内容 |
|---|---|
| 模型接入预设 | 「magpie 本地网关」：协议 OpenAI 兼容、`http://127.0.0.1:3425/v1`、模型名提示 `provider/model` / `group/<id>` |
| 技能 | 「magpie 网关接入与排障」：接入步骤、Key 怎么填、模型名从哪来、连不上时先查什么 |
| 命令 | 「添加 magpie 模型连接」→ 设置区「模型」 |
| 权限 | 网络：`127.0.0.1:3425`；工具上限：`none`（不带工具、不带 Key） |

预设只是把表单填好：**API Key 仍由你自己填**，只存本机安全存储；插件安装不联网、不启动任何进程。

## 用之前

1. 安装并启动 magpie（菜单栏应用或 `magpie serve`），确认 `curl http://127.0.0.1:3425/api/hello` 有响应。
2. 在 magpie 里配好供应商 / 登录订阅账号 —— 多 Key 轮换与额度选路都是它的工作。
3. 和鸣：插件区 → 安装插件 → 选本目录 `plugin.json`。
4. 和鸣 → 设置 → 模型 → 新建连接 → 点「插件带来的模型预设 · magpie 本地网关」，
   API Key 填 `magpie-heming`（本机网关不校验具体值），模型名按 `magpie models` 填。

## 边界

- 和鸣不读 magpie 的账号、订阅与 Key；magpie 的 settings.json / 凭据都在它自己那里。
- 端口以 magpie 的 `settings.json` 为准；改过端口就手动改 Base URL（预设只是默认值）。
- 想让和鸣做「失败自动换人」，请用和鸣的候选链（模型路由页）；magpie 网关侧的选路是另一层，互不冲突。

## 卸载

插件区 → 插件 → 卸载。已添加的模型连接不会被删除（它属于你，不属于插件）；
删掉插件后只是不再显示这个预设。
